# Faktorijel

Ово је најприроднији наставак примера `suma`, само што се уместо сабирања у свакој итерацији користи множење.

Функција `faktorijel` прима један `unsigned` број и враћа `n!`. Циљ је да се утврди:

- `for` петља са бројачем који иде од `1` до `n`
- акумулатор који почиње од `1`
- употреба инструкције `mul`

Референтна C++ верзија функције могла би да изгледа овако:

```cpp
unsigned faktorijel(unsigned n) {
    unsigned rezultat = 1;
    for (unsigned i = 1; i <= n; i++) {
        rezultat *= i;
    }
    return rezultat;
}
```

## Датотеке

- `main.cpp` чита број и исписује `n!`
- `faktorijel.s` садржи асемблерску имплементацију функције

## Превођење

```sh
g++ main.cpp faktorijel.s
```

## Покретање

```sh
./a.out
```

Пример интеракције:

```text
5
5! = 120
```

## На шта треба обратити пажњу

- `0!` је `1`, па акумулатор креће од `1`
- `mul` множи садржај `eax` задатим операндом и цео производ смешта у `edx:eax`
- као и код других `unsigned` примера, овде природно задржавамо само доња 32 бита резултата
