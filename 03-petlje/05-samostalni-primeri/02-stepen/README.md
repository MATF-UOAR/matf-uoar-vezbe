# Stepen

Овај пример утврђује исту идеју као `faktorijel`, али сада функција има два аргумента: базу и број понављања.

Функција `stepen` враћа вредност `a^n` помоћу поновљеног множења. Циљ је да се утврди:

- `for` петља чији број итерација задаје други аргумент
- рад са два `unsigned` аргумента
- почетна вредност резултата `1`

Референтна C++ верзија функције могла би да изгледа овако:

```cpp
unsigned stepen(unsigned a, unsigned n) {
    unsigned rezultat = 1;
    for (unsigned i = 0; i < n; i++) {
        rezultat *= a;
    }
    return rezultat;
}
```

## Датотеке

- `main.cpp` чита базу и експонент и исписује резултат
- `stepen.s` садржи асемблерску имплементацију функције

## Превођење

```sh
g++ main.cpp stepen.s
```

## Покретање

```sh
./a.out
```

Пример интеракције:

```text
3 4
3^4 = 81
```

## На шта треба обратити пажњу

- аргументи `a` и `n` стижу у `edi` и `esi`
- `a^0` је `1`, па зато акумулатор креће од `1`
- услов `i < n` овде у асемблеру записујемо као unsigned поређење
