# Zbir cifara

Овај пример спаја идеју `while` петље из `nzd` са дељењем и остатком при дељењу.

Функција `zbir_cifara` враћа збир свих цифара броја `n`. Циљ је да се утврди:

- `while (n != 0)` петља
- понављана употреба `div` са делиоцем `10`
- издвајање последње цифре преко остатка у `edx`

Референтна C++ верзија функције могла би да изгледа овако:

```cpp
unsigned zbir_cifara(unsigned n) {
    unsigned zbir = 0;
    while (n != 0) {
        zbir += n % 10;
        n /= 10;
    }
    return zbir;
}
```

## Датотеке

- `main.cpp` чита број и исписује збир његових цифара
- `zbir_cifara.s` садржи асемблерску имплементацију функције

## Превођење

```sh
g++ main.cpp zbir_cifara.s
```

## Покретање

```sh
./a.out
```

Пример интеракције:

```text
50271
Zbir cifara: 15
```

## На шта треба обратити пажњу

- пре сваког `div` поново правимо дељеник у `edx:eax`
- последња цифра стиже као остатак у `edx`
- за `n = 0` петља се не извршава ниједном и резултат остаје `0`
