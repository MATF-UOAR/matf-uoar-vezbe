# Broj delilaca

Овај пример комбинује петљу, остатак при дељењу и један једноставан услов унутар тела петље.

Функција `broj_delilaca` враћа број природних делилаца броја `n`. Циљ је да се утврди:

- пролаз кроз цео интервал `1..n`
- провера услова `n % i == 0`
- одвојено чување оригиналног `n`, текућег `i` и бројача делилаца

Референтна C++ верзија функције могла би да изгледа овако:

```cpp
unsigned broj_delilaca(unsigned n) {
    unsigned broj = 0;
    for (unsigned i = 1; i <= n; i++) {
        if (n % i == 0) {
            broj++;
        }
    }
    return broj;
}
```

## Датотеке

- `main.cpp` чита број и исписује број његових делилаца
- `broj_delilaca.s` садржи асемблерску имплементацију функције

## Превођење

```sh
g++ main.cpp broj_delilaca.s
```

## Покретање

```sh
./a.out
```

Пример интеракције:

```text
12
Broj delilaca: 6
```

## На шта треба обратити пажњу

- оригинални `n` чувамо одвојено, јер `div` мења `eax` и `edx`
- унутар петље имамо мали `if`: ако је остатак `0`, увећавамо бројач
- ова верзија је намерно једноставна и пролази кроз све бројеве од `1` до `n`
