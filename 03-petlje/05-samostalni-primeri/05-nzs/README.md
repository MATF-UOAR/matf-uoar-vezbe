# NZS

Ово је најбољи кратак наставак примера `ojler`, јер једна асемблерска функција позива другу, а затим наставља рачунање над добијеним резултатом.

Функција `nzs` враћа најмањи заједнички садржалац бројева `a` и `b`. Циљ је да се утврди:

- позив помоћне функције `nzd`
- чување аргумената који су нам и после `call` потребни
- формула `a / nzd(a, b) * b`

Референтна C++ верзија функције могла би да изгледа овако:

```cpp
unsigned nzd(unsigned a, unsigned b);

unsigned nzs(unsigned a, unsigned b) {
    unsigned d = nzd(a, b);
    if (d == 0) {
        return 0;
    }
    return a / d * b;
}
```

## Датотеке

- `main.cpp` чита два броја и исписује њихов НЗС
- `nzs.s` садржи асемблерску имплементацију функције `nzs`
- `nzd.s` садржи помоћну асемблерску функцију `nzd`

## Превођење

```sh
g++ main.cpp nzs.s nzd.s
```

## Покретање

```sh
./a.out
```

Пример интеракције:

```text
12 18
NZS(12, 18) = 36
```

## На шта треба обратити пажњу

- пре `call nzd` чувамо `a` и `b`, јер су нам и даље потребни после позива
- стек мора да остане исправно поравнат пре `call`
- посебно пазимо на случај `a = 0` и `b = 0`, да не бисмо делили нулом
