# Самостални мини-примери

Ова целина садржи пет кратких готових мини-примера за самосталан рад после треће недеље.

Идеја није да уводи потпуно нове концепте, већ да утврди:

- `while`, `for` и `do-while` стил петљи
- рад са инструкцијама за множење и дељење
- вођење акумулатора и бројача кроз више итерација
- условно извршавање инструкција унутар тела петље
- позив помоћне функције из асемблерске функције
