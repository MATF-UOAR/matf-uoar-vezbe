# Замена две вредности

Ово је најкраћи могући пример у овој недељи: функција не враћа резултат преко `eax`, него мења податке директно у меморији.

## Шта програм ради

Програм учитава два `int` броја, исписује их, затим позива `zameni` и поново их исписује.

Референтна C++ верзија функције може да изгледа овако:

```cpp
void zameni(int& a, int& b) {
    int pom = a;
    a = b;
    b = pom;
}
```

Иако су у C++ потпису параметри референце, на нивоу ABI-ја функција у регистрима заправо добија адресе променљивих које треба заменити.

## Датотеке

- `main.cpp` чита два броја, исписује их пре и после позива
- `zameni.s` чита и уписује вредности преко адреса из `rdi` и `rsi`
- `main_postavi.cpp` чита два броја и позива варијанту која директно уписује константе
- `postavi_01.s` показује зашто је код уписа непосредне вредности потребан `dword ptr`

## Шта треба посматрати у асемблеру

Прво читамо вредности на адресама које су стигле у `rdi` и `rsi`:

```asm
    mov ecx, [rdi]
    mov edx, [rsi]
```

Затим их уписујемо на супротне адресе:

```asm
    mov [rdi], edx
    mov [rsi], ecx
```

Ово је добар први пример за разлику између:

- адресе у регистру, на пример `rdi`
- вредности на тој адреси, на пример `[rdi]`

## Опциона допуна: упис константи

Ако желите само основну идеју ове недеље, прво прођите `zameni`. Варијанта `postavi_01` је кратка допуна после тога, јер уводи још једну идеју: како се у меморију уписује непосредна константа.

Исти фолдер зато садржи и кратку варијанту `postavi_01`, која уместо замене уписује фиксне вредности `0` и `1`:

```cpp
void postavi_01(int& a, int& b) {
    a = 0;
    b = 1;
}
```

У асемблеру то изгледа овако:

```asm
    mov dword ptr [rdi], 0
    mov dword ptr [rsi], 1
```

Овде је важна разлика у односу на `zameni.s`:

- у `mov [rdi], edx` ширина уписа је јасна из регистра `edx`, па посебан `dword ptr` није потребан
- у `mov [rdi], 0` сама константа `0` не говори колико бајтова треба уписати, па то морамо експлицитно да кажемо преко `dword ptr`

Другим речима, `[]` нам говори на коју адресу приступамо, али не и увек колико бајтова уписујемо.

## Превођење

Верзија са заменом:

```sh
g++ main.cpp zameni.s
```

Варијанта са уписом константи:

```sh
g++ main_postavi.cpp postavi_01.s
```

## Покретање

```sh
./a.out
```

Пример интеракције:

```text
3 7
a=3 b=7
a=7 b=3
```

Пример интеракције за `main_postavi.cpp`:

```text
8 9
a=8 b=9
a=0 b=1
```

## На шта треба обратити пажњу

- ово је намерно једноставан уводни пример, јер први пут директно уписујемо у меморију
- унутар саме функције референце можемо да посматрамо исто као показиваче: у регистрима су адресе
- функција ништа не враћа, али мења стање програма зато што уписује нове вредности на постојеће адресе
- варијанта `postavi_01` је намерно остављена као кратка допуна, после основне идеје замене преко адреса
- у `postavi_01` се први пут јасно види да адреса и ширина меморијског операнда нису исто
