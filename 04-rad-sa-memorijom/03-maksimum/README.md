# Максимум низа

Овај пример задржава исти пролаз кроз низ као у претходном задатку, али уместо збира одржава текући максимум.

## Шта програм ради

Програм учитава дужину низа, затим елементе и исписује највећу вредност.

Референтна C++ функција може да изгледа овако:

```cpp
int max(int* niz, int n) {
    if (n <= 0) {
        return 0;
    }

    int tekuci_maks = niz[0];
    for (int i = 1; i < n; i++) {
        if (tekuci_maks < niz[i]) {
            tekuci_maks = niz[i];
        }
    }
    return tekuci_maks;
}
```

У недељи 4 подразумевамо да је улазни низ непразан, па је главна идеја овог примера избор почетне вредности и њено касније ажурирање. Асемблерска имплементација ипак на почетку има и кратку заштиту за `n <= 0`.

## Датотеке

- `main.cpp` чита низ и исписује максимум
- `max.s` пролази кроз низ и ажурира текући максимум

## Шта треба посматрати у асемблеру

На почетку у `r8d` смештамо `a[0]`, па тај регистар представља текући максимум:

```asm
    mov r8d, [rdi]
```

У свакој итерацији учитавамо следећи елемент:

```asm
    mov r9d, [rdi + 4*rcx]
```

Затим поредимо `tekuci_maks` и `a[i]`. Ако је нови елемент већи, ажурирамо максимум:

```asm
    cmp r8d, r9d
    jg nastavak
    mov r8d, r9d
```

Овде је важно да су елементи типа `int`, па поређење читамо као означено поређење.

Мали траг извршавања за низ `7 2 9 1 4` изгледа овако:

| Корак | Текући елемент | `tekuci_maks` после поређења |
| --- | --- | --- |
| почетак | `a[0] = 7` | `7` |
| `i = 1` | `2` | `7` |
| `i = 2` | `9` | `9` |
| `i = 3` | `1` | `9` |
| `i = 4` | `4` | `9` |

## Превођење

```sh
g++ main.cpp max.s
```

## Покретање

```sh
./a.out
```

Пример интеракције:

```text
5
7 2 9 1 4
9
```

## На шта треба обратити пажњу

- овај пример показује типичан образац „узми први елемент као почетну вредност, па остатак низа користи за ажурирање“
- у објашњењу подразумевамо `n > 0`, али сама имплементација ипак има и кратку заштиту за `n <= 0`
- адресирање елемента је исто као у примеру са сумом; ново је само условно ажурирање резултата
