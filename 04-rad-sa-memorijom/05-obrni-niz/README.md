# Обртање низа

Овај пример показује измену низа „у месту“: елементи се не копирају у нови низ, већ се мењају директно на постојећим адресама.

## Шта програм ради

Програм учитава дужину низа и његове елементе, позива `obrni`, а затим исписује елементе у обрнутом редоследу.

Референтна C++ функција може да изгледа овако:

```cpp
void obrni(int* niz, int n) {
    int i = 0;
    int j = n - 1;

    while (i < j) {
        int pom = niz[i];
        niz[i] = niz[j];
        niz[j] = pom;
        i++;
        j--;
    }
}
```

## Датотеке

- `main.cpp` чита низ, позива `obrni` и исписује резултат
- `obrni.s` реализује решење преко индекса `i` и `j`
- `obrni_v2.s` реализује исту идеју преко две адресе које се крећу ка средини

## Шта треба посматрати у асемблеру

У првој верзији (`obrni.s`) радимо исто што и у C++:

- `ecx` игра улогу индекса `i`
- `edx` игра улогу индекса `j`
- приступ елементима иде преко обрасца `baza + indeks * velicina_elementa`, овде `[rdi + 4 * indeks]`

У другој верзији (`obrni_v2.s`) не чувамо индексе, него готове адресе:

```asm
    mov rcx, rdi
    lea rdx, [rdi + 4*rsi - 4]
```

Тада `rcx` показује на леви крај, а `rdx` на десни крај низа. После сваке замене:

```asm
    add rcx, 4
    sub rdx, 4
```

Тако се две адресе крећу једна ка другој.

У верзији са адресама је важан и рани излаз за `n <= 1`, да се не би рачунала адреса `&a[n-1]` кад нема шта да се обрће.

Кад касније поредимо `rcx` и `rdx`, поредимо саме адресе. Адресе читамо као неозначене вредности, па услов „лева адреса је стигла до десне или је прешла преко ње“ записујемо скоком `jae`, а не `jge`.

Кратко поређење две верзије:

| Верзија | Шта чувамо током петље | Како долазимо до елемента |
| --- | --- | --- |
| индексна | индексе `i` и `j` | сваки пут преко `baza + indeks * velicina_elementa` |
| верзија са адресама | адресу левог и адресу десног елемента | адресе се једном израчунају, па се после само померају за `4` бајта |

## Превођење

Верзија са индексима:

```sh
g++ main.cpp obrni.s
```

Верзија са адресама:

```sh
g++ main.cpp obrni_v2.s
```

## Покретање

```sh
./a.out
```

Пример интеракције:

```text
5
1 2 3 4 5
5 4 3 2 1 
```

## На шта треба обратити пажњу

- оба фајла раде исту ствар, али један користи индексе, а други директне адресе
- ово је добар пример да се упореде „индексни“ и „адресни“ начин размишљања
- замена елемената је иста идеја као у `01-swap`, само сада адресе више не стижу споља, већ их сами рачунамо из базе низа
