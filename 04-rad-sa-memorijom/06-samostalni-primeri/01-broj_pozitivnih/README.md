# Број позитивних

Ово је најкраћи природни наставак примера `Сума елемената низа`, само што се уместо сабирања сваки елемент проверава и по потреби повећава бројач.

Функција `broj_pozitivnih` прима низ и његову дужину и враћа колико елемената у низу има вредност већу од нуле. Циљ је да се утврди:

- пролазак кроз цео низ
- поређење сваког елемента са нулом
- одвојено вођење индекса и бројача резултата

Референтна C++ верзија функције могла би да изгледа овако:

```cpp
int broj_pozitivnih(int* niz, int n) {
    int broj = 0;
    for (int i = 0; i < n; i++) {
        if (niz[i] > 0) {
            broj++;
        }
    }
    return broj;
}
```

## Датотеке

- `main.cpp` чита дужину низа и његове елементе, а затим исписује резултат
- `broj_pozitivnih.s` садржи асемблерску имплементацију функције

## Шта треба посматрати у асемблеру

И овде задржавамо исти образац адресирања као у главним примерима недеље:

```asm
    cmp dword ptr [rdi + 4*rcx], 0
```

`rdi` је базна адреса низа, `ecx` је индекс, а резултат држимо у `eax`. Ново је само то што сваки елемент не сабирамо, него га прво поредимо са нулом и тек онда по потреби увећавамо бројач.

## Превођење

```sh
g++ main.cpp broj_pozitivnih.s
```

## Покретање

```sh
./a.out
```

Пример интеракције:

```text
5
-2 0 7 3 -1
2
```

## На шта треба обратити пажњу

- нула се не броји као позитиван елемент
- приступ елементу низа је и даље облика `[rdi + 4 * индекс]`
- главна разлика у односу на `Суму елемената низа` је што резултат не зависи од вредности елемента, него од исхода поређења
