# Minimum

Ово је најприроднији парњак примеру `Максимум низа`: структура петље је скоро иста, само што сада тражимо најмањи елемент.

Функција `minimum` прима низ и његову дужину и враћа најмањи елемент низа. Циљ је да се утврди:

- иницијализација текућег резултата првим елементом
- условно ажурирање када наиђемо на мању вредност
- посебан случај празног низа

Референтна C++ верзија функције могла би да изгледа овако:

```cpp
int minimum(int* niz, int n) {
    if (n <= 0) {
        return 0;
    }

    int min = niz[0];
    for (int i = 1; i < n; i++) {
        if (niz[i] < min) {
            min = niz[i];
        }
    }
    return min;
}
```

## Датотеке

- `main.cpp` чита низ и исписује његов минимум
- `minimum.s` садржи асемблерску имплементацију функције

## Шта треба посматрати у асемблеру

Ово је скоро исти образац као код `Максимума низа`: прво узимамо `a[0]` као текући резултат, па затим обилазимо остатак низа.

```asm
    mov r8d, [rdi]
    mov r9d, [rdi + 4*rcx]
```

Разлика је само у смеру поређења: овде ажурирамо текући минимум кад наиђемо на мањи елемент.

## Превођење

```sh
g++ main.cpp minimum.s
```

## Покретање

```sh
./a.out
```

Пример интеракције:

```text
5
4 -2 7 0 3
-2
```

## На шта треба обратити пажњу

- у материјалу подразумевамо `n > 0`, а ова имплементација уз то има и кратку заштиту за `n <= 0`
- почетни минимум је `niz[0]`, па петља креће од `i = 1`
- пошто радимо са типом `int`, поређење треба да буде потписано
