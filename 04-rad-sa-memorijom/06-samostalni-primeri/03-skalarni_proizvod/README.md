# Скаларни производ

Ово је добар кратак пример у ком једна петља истовремено пролази кроз два низа и комбинује њихове елементе.

Функција `skalarni_proizvod` прима два низа исте дужине и враћа збир производа одговарајућих елемената. Циљ је да се утврди:

- рад са две базне адресе у истој петљи
- читање `a[i]` и `b[i]` за исти индекс
- множење пара елемената и сабирање у акумулатор

Референтна C++ верзија функције могла би да изгледа овако:

```cpp
int skalarni_proizvod(int* a, int* b, int n) {
    int suma = 0;
    for (int i = 0; i < n; i++) {
        suma += a[i] * b[i];
    }
    return suma;
}
```

## Датотеке

- `main.cpp` чита дужину и два низа, а затим исписује њихов скаларни производ
- `skalarni_proizvod.s` садржи асемблерску имплементацију функције

## Шта треба посматрати у асемблеру

Овде први пут у истој петљи користимо две различите базне адресе:

```asm
    mov eax, [rdi + 4*rcx]
    imul eax, dword ptr [rsi + 4*rcx]
```

Индекс `ecx` је исти за оба низа, али се један елемент чита преко `rdi`, а други преко `rsi`. После множења производ додајемо на текућу суму.

## Превођење

```sh
g++ main.cpp skalarni_proizvod.s
```

## Покретање

```sh
./a.out
```

Пример интеракције:

```text
3
1 2 3
4 5 6
32
```

## На шта треба обратити пажњу

- аргументи стижу у `rdi`, `rsi` и `edx`
- пре множења морамо да учитамо бар један операнд у регистар
- ово је добар кратак пример да видите како један индекс може истовремено да адресира два различита низа
