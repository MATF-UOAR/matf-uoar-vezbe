# Замена минимума и максимума

Ово је добар завршни мини-задатак за ову недељу, јер спаја идеје из примера `Максимум низа` и `Замена две вредности`.

Функција `zameni_min_i_max` пронађе позиције минималног и максималног елемента, а затим те две вредности замени у самом низу. Циљ је да се утврди:

- памћење индекса најмањег и највећег елемента
- пролаз кроз низ уз више условних ажурирања
- каснија измена меморије на пронађеним позицијама

Референтна C++ верзија функције могла би да изгледа овако:

```cpp
void zameni_min_i_max(int* niz, int n) {
    if (n <= 1) {
        return;
    }

    int i_min = 0;
    int i_max = 0;

    for (int i = 1; i < n; i++) {
        if (niz[i] < niz[i_min]) {
            i_min = i;
        }
        if (niz[i] > niz[i_max]) {
            i_max = i;
        }
    }

    int pom = niz[i_min];
    niz[i_min] = niz[i_max];
    niz[i_max] = pom;
}
```

## Датотеке

- `main.cpp` чита низ, позива `zameni_min_i_max` и исписује измењени низ
- `zameni_min_i_max.s` садржи асемблерску имплементацију функције

## Шта треба посматрати у асемблеру

Овај задатак има две јасне фазе.

У првој фази петља памти индексе минимума и максимума:

```asm
    cmp eax, r10d
    jge proveri_maksimum

    cmp eax, r11d
    jle dalje
```

У другој фази, кад су обе позиције већ познате, радимо једну класичну замену вредности на пронађеним адресама:

```asm
    mov eax, [rdi + 4*r8]
    mov edx, [rdi + 4*r9]
    mov [rdi + 4*r8], edx
    mov [rdi + 4*r9], eax
```

## Превођење

```sh
g++ main.cpp zameni_min_i_max.s
```

## Покретање

```sh
./a.out
```

Пример интеракције:

```text
5
4 -2 7 0 3
4 7 -2 0 3 
```

## На шта треба обратити пажњу

- ако је `n <= 1`, нема шта да се мења и функција одмах излази
- са строгим поређењима `<` и `>` остају запамћене прве појаве минимума и максимума
- сама замена иде тек после проласка кроз низ, кад су обе позиције већ познате
- ово је добар мини-задатак да се види како једна петља може да припреми податке за каснију измену меморије
