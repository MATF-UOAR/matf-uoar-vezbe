# Следећи ID

Ово је најкраћи пример у недељи и на њему видимо најчистији облик функције са статичким стањем.

- функција може да има сопствени статички податак који живи ван стека
- вредност тог податка може да се мења из позива у позив

## Шта програм ради

Програм више пута позива функцију `sledeci_id`. Та функција памти последњи додељени број и сваки пут враћа следећи.

Референтна C++ верзија могла би да изгледа овако:

```cpp
unsigned sledeci_id() {
    static unsigned poslednji_id = 0;
    poslednji_id++;
    return poslednji_id;
}
```

## Датотеке

- `main.cpp` више пута позива `sledeci_id` и исписује повратну вредност
- `sledeci_id.s` садржи асемблерску имплементацију функције

## Шта треба посматрати у асемблеру

Статички бројач није локална променљива на стеку, него податак са статичким животним веком:

```asm
.bss
poslednji_id: .zero 4
```

То је асемблерски еквивалент C++ локалне `static` променљиве: домет јој је „везан“ за функцију, али вредност преживљава између више позива.

Секција `.bss` се користи за податке који имају статички животни век и почетну вредност нула, па `poslednji_id` на почетку програма већ има вредност `0`.

Такође користимо `.align 4` директиву да би се постарали да се наша статичка променљива налази на адреси која је дељива са 4 . Ово је корисно
пошто олакшава читање податка из меморије, тзв. Aligned Access. 
У сваком позиву само увећавамо ту вредност у меморији и затим је враћамо преко `eax`:

```asm
add dword ptr [rip + poslednji_id], 1
mov eax, [rip + poslednji_id]
```

Облик `[rip + poslednji_id]` значи да се симболу приступа релативно у односу на тренутну инструкцију. То је уобичајен начин да се у 64-битном коду дохвати глобални или статички податак.

Иако овде нема позива друге функције, и даље задржавамо `enter` и `leave` да би запис био уједначен са осталим примерима у недељи.

## Превођење

```sh
g++ main.cpp sledeci_id.s
```

## Покретање

```sh
./a.out
```

Пример излаза:

```text
1
2
3
4
```

## На шта треба обратити пажњу

- `poslednji_id` није на стеку, па се не брише после `leave`
- обична локална вредност припада једном позиву функције, а статичка вредност припада целом трајању програма
- `enter` и `leave` овде нису неопходни, али држе запис уједначеним са остатком недеље
