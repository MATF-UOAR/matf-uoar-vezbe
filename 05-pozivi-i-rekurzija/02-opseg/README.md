# Опсег низа

Овај пример показује природну ситуацију у којој локална вредност мора да преживи један позив функције да би нам и даље била потребна после следећег.

## Шта програм ради

Програм учитава низ целих бројева, а функција `opseg` враћа разлику између максималног и минималног елемента.

Подразумевамо да је `n > 0`, јер и `minimum` и `maksimum` крећу од `a[0]` као почетне вредности.

Референтна C++ верзија могла би да изгледа овако:

```cpp
int minimum(int* a, int n) {
    int min = a[0];
    for (int i = 1; i < n; i++) {
        if (a[i] < min) {
            min = a[i];
        }
    }
    return min;
}

int maksimum(int* a, int n) {
    int max = a[0];
    for (int i = 1; i < n; i++) {
        if (a[i] > max) {
            max = a[i];
        }
    }
    return max;
}

int opseg(int* a, int n) {
    int min = minimum(a, n);
    int max = maksimum(a, n);
    return max - min;
}
```

## Датотеке

- `main.cpp` учитава низ и позива `opseg`
- `minimum.s` налази минимум низа
- `maksimum.s` налази максимум низа
- `opseg.s` позива обе функције и враћа њихову разлику

## Шта треба посматрати у асемблеру

У `opseg` три вредности морају да преживе два одвојена позива: база низа `a`, дужина `n` и минимум добијен из `minimum`.

| вредност | где је чувамо | зашто мора да преживи |
| --- | --- | --- |
| `a` | `[rbp - 8]` | треба нам као први аргумент за `maksimum` |
| `n` | `[rbp - 12]` | треба нам као други аргумент за `maksimum` |
| `min` | `[rbp - 16]` | треба нам после `maksimum`, да израчунамо `max - min` |

Зато на уласку чувамо аргументе, а после првог позива и добијени минимум:

```asm
mov [rbp - 8], rdi
mov [rbp - 12], esi
...
mov [rbp - 16], eax
```

После `call minimum` не смемо да претпоставимо да су `rdi`, `esi` или `eax` задржали старе вредности. `eax` управо садржи повратну вредност функције `minimum`, али ће га следећи позив преписати, па минимум морамо да склонимо у стек оквир.

Тек после тога смемо безбедно да пређемо на други позив:

```asm
call minimum
...
call maksimum
```

Тако стек оквир у `opseg` није ту зато што некој функцији прослеђујемо адресу локалне променљиве, него зато што нам најважније вредности морају остати доступне док се други `call` не заврши.

Тек после `call maksimum` имамо оба податка која су нам потребна, па рачунамо:

```asm
sub eax, [rbp - 16]
```

## Превођење

```sh
g++ main.cpp opseg.s minimum.s maksimum.s
```

## Покретање

```sh
./a.out
```

Пример интеракције:

```text
5
-2 7 3 9 -5
14
```

## На шта треба обратити пажњу

- `opseg` има локалне променљиве не зато што некоме прослеђујемо њихову адресу, него зато што нам вредности требају и после других `call` инструкција
- `minimum` и `maksimum` су функције које саме не позивају друге функције, али и даље задржавамо `enter` и `leave` ради јасноће
- подразумевамо да је `n > 0`, па први елемент може да послужи као почетни минимум и максимум
