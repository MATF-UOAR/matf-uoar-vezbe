# Опсег низа

Овај пример показује природну ситуацију у којој локална вредност мора да преживи један позив функције да би нам и даље била потребна после следећег.

## Шта програм ради

Програм учитава низ целих бројева, а функција `opseg` враћа разлику између максималног и минималног елемента.

Референтна C++ верзија могла би да изгледа овако:

```cpp
int minimum(int* a, int n) {
    int min = a[0];
    for (int i = 1; i < n; i++) {
        if (a[i] < min) {
            min = a[i];
        }
    }
    return min;
}

int maksimum(int* a, int n) {
    int max = a[0];
    for (int i = 1; i < n; i++) {
        if (a[i] > max) {
            max = a[i];
        }
    }
    return max;
}

int opseg(int* a, int n) {
    int min = minimum(a, n);
    int max = maksimum(a, n);
    return max - min;
}
```

## Датотеке

- `main.cpp` учитава низ и позива `opseg`
- `minimum.s` налази минимум низа
- `maksimum.s` налази максимум низа
- `opseg.s` позива обе функције и враћа њихову разлику

## Шта треба посматрати у асемблеру

У `opseg` је важан редослед позива:

```asm
call minimum
...
call maksimum
```

После првог позива у `eax` добијамо минимум, али други позив ће преписати `eax`. Зато минимум чувамо као локалну вредност у стек оквиру:

```asm
mov dword ptr [rbp - 16], eax
```

Исто важи и за аргументе `a` и `n`: после `call minimum` не смемо да претпоставимо да су `rdi` и `esi` остали непромењени, па их зато такође чувамо у стек оквиру и враћамо пре другог позива.

Тек после `call maksimum` имамо оба податка која су нам потребна, па рачунамо:

```asm
sub eax, dword ptr [rbp - 16]
```

## Превођење

```sh
g++ main.cpp opseg.s minimum.s maksimum.s
```

## Покретање

```sh
./a.out
```

Пример интеракције:

```text
5
-2 7 3 9 -5
14
```

## На шта треба обратити пажњу

- `opseg` има локалне променљиве не зато што некоме прослеђујемо њихову адресу, него зато што нам вредности требају и после других `call` инструкција
- `minimum` и `maksimum` су leaf функције, али и даље задржавамо `enter` и `leave` ради јасноће
- подразумевамо да је `n > 0`, па први елемент може да послужи као почетни минимум и максимум
