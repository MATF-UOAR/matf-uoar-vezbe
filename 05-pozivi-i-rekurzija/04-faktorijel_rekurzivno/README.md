# Рекурзивни факторијел

Ово је најкраћи рекурзивни пример у материјалима и природан је наставак итеративног факторијела из недеље 3.

## Шта програм ради

Функција `faktorijel_rekurzivno` враћа `n!` користећи класичну дефиницију:

- ако је `n <= 1`, резултат је `1`
- иначе је `n! = n * (n - 1)!`

Референтна C++ верзија могла би да изгледа овако:

```cpp
unsigned faktorijel_rekurzivno(unsigned n) {
    if (n <= 1) {
        return 1;
    }

    return n * faktorijel_rekurzivno(n - 1);
}
```

## Датотеке

- `main.cpp` учитава број и позива `faktorijel_rekurzivno`
- `faktorijel_rekurzivno.s` садржи асемблерску имплементацију функције

## Шта треба посматрати у асемблеру

Величина стек оквира је мало већа него што бисмо очекивали само по једној локалној вредности:

```asm
enter 16, 0
```

Суштински нам треба сачувано оригинално `n`, а остатак простора држи рекурзивни `call` у уредном, поравнатом облику. Иако чувамо само један `int`, функција ће сама позвати другу функцију, па стек оквир мора да остави стек у облику који поштује правило о поравнању.

### Спуст у рекурзију

Пре рекурзивног позива чувамо оригиналну вредност `n` у стек оквиру:

```asm
mov [rbp - 4], edi
```

То је важно зато што после позива желимо да добијени резултат помножимо баш старом вредношћу `n`, а не вредношћу `n - 1`.

Базни случај је директан:

```asm
cmp edi, 1
ja rekurzivni_slucaj

mov eax, 1
```

Пошто је `n` типа `unsigned`, инструкција `ja` овде значи "иди у рекурзивни случај ако је `n > 1`".

А у рекурзивном случају видимо да не постоји никаква „посебна“ рекурзивна инструкција:

```asm
dec edi
call faktorijel_rekurzivno
```

То је обичан `call`, само што циљни симбол има исто име као функција у којој се већ налазимо. Током тог спуста сваки нови стек оквир памти сопствено `n` и чека резултат дубљег позива.

### Повратак и одмотавање

После повратка из дубљег позива, у `eax` још није коначан резултат за стари `n`, него факторијел од `n - 1`. Зато тек сада користимо сачувану оригиналну вредност:

```asm
mul dword ptr [rbp - 4]
```

То је тренутак у ком се рекурзија „одмотава“: сваки стек оквир добије резултат из дубљег оквира, допуни га својим `n` и онда се враћа назад.

Кратак траг за `n = 3` изгледа овако:

```text
f(3) чека резултат f(2)
f(2) чека резултат f(1)
f(1) враћа 1
f(2) враћа 2 * 1 = 2
f(3) враћа 3 * 2 = 6
```

У анимацији су адресе симболичне. Важан вредности су: `edi` који садржи вредност аргумента, `[rbp - 4]` који чува старо `n` у сваком оквиру, а `eax` који садржи резултат при повратку.

## Превођење

```sh
g++ main.cpp faktorijel_rekurzivno.s
```

## Покретање

```sh
./a.out
```

Пример интеракције:

```text
5
5! = 120
```

## На шта треба обратити пажњу

- `0!` и `1!` су `1`, па зато користимо услов `n <= 1`
- сваки рекурзивни позив прави нови стек оквир
- локално смештање оригиналног `n` је кључни детаљ који омогућава множење после повратка из рекурзије
