# Рекурзивни палиндром

Ово је најбогатији пример у недељи: спаја рад са ниском, показивачима и рекурзивним позивом.

## Шта програм ради

Јавна функција `palindrom_rekurzivno` прима само адресу почетка ниске. Она прво пронађе крај стринга, а затим позове интерну helper функцију која упоређује леви и десни крај и рекурзивно се помера ка средини.

Референтна C++ верзија могла би да изгледа овако:

```cpp
int palindrom_opseg(const char* levo, const char* desno) {
    if (levo >= desno) {
        return 1;
    }

    if (*levo != *desno) {
        return 0;
    }

    return palindrom_opseg(levo + 1, desno - 1);
}

int palindrom_rekurzivno(const char* s) {
    const char* kraj = s;
    while (*kraj != '\0') {
        kraj++;
    }

    return palindrom_opseg(s, kraj - 1);
}
```

## Датотеке

- `main.cpp` учитава ниску и позива `palindrom_rekurzivno`
- `palindrom_rekurzivno.s` садржи јавну функцију и интерну helper функцију

## Шта треба посматрати у асемблеру

У јавној функцији прво пролазимо кроз ниску док не нађемо `'\0'`. То је исти онај образац кретања кроз меморију који смо већ видели код низова и показивача.

Када helper функција добије два показивача, базни случај гласи:

```asm
cmp rdi, rsi
jae jeste
```

Овде поредимо адресе, па је природно да користимо unsigned поређење. Ако су се леви и десни крај срели или прешли један преко другог, преостали део ниске је палиндром.

Ако крајњи карактери нису једнаки, одмах враћамо `0`. У супротном, померамо оба показивача и рекурзивно позивамо helper:

```asm
inc rdi
dec rsi
call palindrom_opseg
```

## Превођење

```sh
g++ main.cpp palindrom_rekurzivno.s
```

## Покретање

```sh
./a.out
```

Пример интеракције:

```text
anavolimilovana
palindrom
```

## На шта треба обратити пажњу

- helper функција није означена као `.global`, јер није део јавног интерфејса
- ово је пример у ком рекурзија ради над адресама, а не над бројевима
- празна ниска и ниска дужине `1` природно падају у базни случај
