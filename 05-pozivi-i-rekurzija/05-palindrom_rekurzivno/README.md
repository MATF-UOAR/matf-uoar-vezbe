# Рекурзивни палиндром

Ово је најбогатији пример у недељи: спаја рад са ниском, показивачима и рекурзивним позивом.

## Шта програм ради

Јавна функција `palindrom_rekurzivno` прима само адресу почетка ниске. Ако је ниска празна, одмах враћа `1`. У супротном прво пронађе крај ниске, а затим позове интерну помоћну функцију која упоређује леви и десни крај и рекурзивно се помера ка средини.

Референтна C++ верзија могла би да изгледа овако:

```cpp
int palindrom_opseg(const char* levo, const char* desno) {
    if (levo >= desno) {
        return 1;
    }

    if (*levo != *desno) {
        return 0;
    }

    return palindrom_opseg(levo + 1, desno - 1);
}

int palindrom_rekurzivno(const char* s) {
    if (*s == '\0') {
        return 1;
    }

    const char* kraj = s;
    while (*kraj != '\0') {
        kraj++;
    }

    return palindrom_opseg(s, kraj - 1);
}
```

## Датотеке

- `main.cpp` учитава ниску и позива `palindrom_rekurzivno`
- `palindrom_rekurzivno.s` садржи јавну функцију и интерну помоћну функцију

## Шта треба посматрати у асемблеру

Јавна функција прво решава посебан случај празне ниске, тако да не правимо адресу `kraj - 1` пре почетка саме ниске:

```asm
mov rsi, rdi
cmp byte ptr [rsi], 0
je prazna_niska
```

Тек после тога пролазимо кроз ниску док не нађемо `'\0'`. То је исти онај образац кретања кроз меморију који смо већ видели код низова и показивача.

Када се та петља заврши, `kraj` показује на завршни карактер `'\0'`, а последњи стварни карактер је на адреси `kraj - 1`. Зато јавна функција помоћној функцији прослеђује баш укључиве границе опсега који још треба проверити.

Када помоћна функција добије два показивача, базни случај гласи:

```asm
cmp rdi, rsi
jae jeste
```

Овде поредимо адресе, па је природно да користимо unsigned поређење. Поређење има смисла јер оба показивача припадају истој ниски. Ако су се леви и десни крај срели или прешли један преко другог, преостали део ниске је палиндром.

Ако крајњи карактери нису једнаки, одмах враћамо `0`. У супротном, померамо оба показивача и рекурзивно позивамо помоћну функцију:

```asm
inc rdi
dec rsi
call palindrom_opseg
```

Овде је важно да оба показивача померамо симетрично: леви иде удесно ка средини, десни улево ка средини, а услов `levo >= desno` зауставља рекурзију чим више нема непроверених парова карактера.

## Превођење

```sh
g++ main.cpp palindrom_rekurzivno.s
```

## Покретање

```sh
./a.out
```

Пример интеракције када је унос палиндром:

```text
anavolimilovana
palindrom
```

Пример интеракције када унос није палиндром:

```text
program
nije palindrom
```

## На шта треба обратити пажњу

- помоћна функција није означена као `.global`, јер није део јавног интерфејса
- ово је пример у ком рекурзија ради над адресама, а не над бројевима
- празна ниска се обрађује у јавној функцији пре формирања `kraj - 1`
- ниска дужине `1` природно пада у базни случај помоћне функције
