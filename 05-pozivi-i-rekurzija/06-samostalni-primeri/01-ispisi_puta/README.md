# Испиши више пута

Ово је кратак пример у ком једна асемблерска функција више пута позива библиотечку функцију `puts`.

## Шта програм ради

Програм учитава број `n` и ниску, а функција `ispisi_puta` исписује ту ниску `n` пута.

Фокус није на рекурзији, него на томе да адреса ниске и бројач петље преживе више `call` инструкција.

Референтна C++ верзија:

```cpp
void ispisi_puta(const char* s, unsigned n) {
    while (n != 0) {
        puts(s);
        n--;
    }
}
```

## Шта треба посматрати у асемблеру

`puts` је спољни позив, па `ispisi_puta` мора сама да сачува адресу ниске и бројач петље ако су јој потребни после повратка из `puts`.

## Превођење

```sh
g++ main.cpp ispisi_puta.s
```

## Покретање

```sh
./a.out
```

Пример интеракције:

```text
3
zdravo
zdravo
zdravo
zdravo
```

## На шта треба обратити пажњу

- адреса ниске мора да преживи више позива `puts`
- бројач петље такође мора да остане исправан после сваког `call`
- услов `n == 0` само одређује излаз из петље; суштина примера је у више узастопних позива исте функције
