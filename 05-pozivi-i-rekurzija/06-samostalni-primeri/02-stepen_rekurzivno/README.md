# Рекурзивни степен

Ово је кратак рекурзивни пример са два аргумента.

## Шта програм ради

Функција `stepen_rekurzivno` рачуна `a^n` тако што један степен смањује проблем на `a^(n - 1)`.

Референтна C++ верзија:

```cpp
unsigned stepen_rekurzivno(unsigned a, unsigned n) {
    if (n == 0) {
        return 1;
    }

    return a * stepen_rekurzivno(a, n - 1);
}
```

## Шта треба посматрати у асемблеру

Пре рекурзивног позива чувамо базу `a`, јер после повратка треба да помножимо добијени резултат баш оригиналном базом. Стари експонент `n` нам после повратка више није потребан.

Кратак траг за `2^3`:

```text
stepen(2, 3) чека stepen(2, 2)
stepen(2, 2) чека stepen(2, 1)
stepen(2, 1) чека stepen(2, 0)
stepen(2, 0) враћа 1
резултати се враћају као 2, 4, 8
```

Као додатни задатак, можете да пробате бржу рекурзивну верзију степеновања коју сте видели на Уводу у алгоритме: за паран `n` рачуна се `a^(n / 2)` па се тај резултат квадрира, а за непаран `n` се још једном множи са `a`.

## Превођење

```sh
g++ main.cpp stepen_rekurzivno.s
```

## Покретање

```sh
./a.out
```

Пример интеракције:

```text
2 3
2^3 = 8
```

## На шта треба обратити пажњу

- базни случај је `n == 0`, јер је `a^0 = 1`
- база `a` мора да се сачува пре рекурзивног позива
- при повратку се рекурзија одмотава тако што добијени резултат множимо сачуваном базом `a`
