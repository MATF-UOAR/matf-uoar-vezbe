# Рекурзивна сума низа

Ово је пример у ком се рекурзија користи над низом, а не над једним бројем или ниском.

Референтна C++ верзија:

```cpp
int zbir_niza_rekurzivno(int* a, int n) {
    if (n == 0) {
        return 0;
    }

    return a[0] + zbir_niza_rekurzivno(a + 1, n - 1);
}
```

## Превођење

```sh
g++ main.cpp zbir_niza_rekurzivno.s
```

## На шта треба обратити пажњу

- после читања `a[0]` адресу базе померамо на следећи елемент
- вредност првог елемента мора да се сачува до повратка из рекурзије
