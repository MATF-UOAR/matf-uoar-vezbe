# Рекурзивна сума низа

Ово је пример у ком се рекурзија користи над низом, а не над једним бројем или ниском.

## Шта програм ради

Функција `zbir_niza_rekurzivno` враћа збир првих `n` елемената низа.

Референтна C++ верзија:

```cpp
int zbir_niza_rekurzivno(int* a, int n) {
    if (n == 0) {
        return 0;
    }

    return a[0] + zbir_niza_rekurzivno(a + 1, n - 1);
}
```

## Шта треба посматрати у асемблеру

Израз `a + 1` у C++ значи "адреса следећег елемента", а пошто су елементи типа `int`, у асемблеру се база низа помера за `4` бајта.

Вредност `a[0]` мора да се сачува пре рекурзивног позива, јер ће повратна вредност дубљег позива стићи у `eax`, а тек после тога додајемо сачувани први елемент.

Кратак траг за низ `[2, -5, 7]`:

```text
2 + zbir([-5, 7])
-5 + zbir([7])
7 + zbir([])
0
7
2
4
```

## Превођење

```sh
g++ main.cpp zbir_niza_rekurzivno.s
```

## Покретање

```sh
./a.out
```

Пример интеракције:

```text
3
2 -5 7
4
```

## На шта треба обратити пажњу

- базни случај је `n == 0`, када је збир празног остатка низа једнак `0`
- после читања `a[0]` адресу базе померамо на следећи елемент
- вредност првог елемента мора да се сачува пре рекурзивног позива и додаје се тек при одмотавању
