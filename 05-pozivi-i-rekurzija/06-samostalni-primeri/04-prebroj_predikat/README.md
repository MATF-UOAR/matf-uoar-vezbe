# Преброј преко predicate функције

Ово је кратак пример са индиректним `call`, али за разлику од `nadji_prvi` не стајемо на првом поготку него обилазимо цео низ.

## Шта програм ради

Функција `prebroj_predikat` броји колико елемената низа даје ненула резултат када се над њима позове прослеђена predicate функција.

Референтна C++ верзија:

```cpp
int prebroj_predikat(unsigned* a, int n, int (*pred)(unsigned)) {
    int broj = 0;
    for (int i = 0; i < n; i++) {
        if (pred(a[i])) {
            broj++;
        }
    }
    return broj;
}
```

## Шта треба посматрати у асемблеру

Механизам индиректног позива је исти као у `nadji_prvi`: адреса функције стиже као аргумент, чува се у стек оквиру и позива преко те адресе. Разлика је у току контроле: овде после поготка не враћамо резултат одмах, него увећавамо бројач и настављамо кроз остатак низа.

| вредност | зашто се чува |
| --- | --- |
| `a` | да после сваког `call` можемо да дохватимо следећи елемент |
| `pred` | да у свакој итерацији можемо да урадимо индиректан позив |
| `n` | да знамо где се петља завршава |
| `i` | да наставимо петљу после повратка из `pred` |
| `broj` | да се број погодака не изгуби после следећег `call` |

## Превођење

```sh
g++ main.cpp prebroj_predikat.s
```

## Покретање

```sh
./a.out
```

Пример интеракције:

```text
6
11 15 18 21 130 7
parnih: 2
> 99: 1
```

## На шта треба обратити пажњу

- адреса predicate функције мора да остане доступна у свакој итерацији
- бројач погодака мора да преживи сваки индиректан `call`
- за разлику од `nadji_prvi`, овде нема ране завршнице: и после поготка настављамо даље кроз низ
