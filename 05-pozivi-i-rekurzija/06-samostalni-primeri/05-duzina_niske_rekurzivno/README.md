# Рекурзивна дужина ниске

Ово је кратак пример рекурзије над показивачем на карактере.

## Шта програм ради

Функција `duzina_niske_rekurzivno` враћа број карактера пре завршног `'\0'`.

Референтна C++ верзија:

```cpp
int duzina_niske_rekurzivno(const char* s) {
    if (*s == '\0') {
        return 0;
    }

    return 1 + duzina_niske_rekurzivno(s + 1);
}
```

## Шта треба посматрати у асемблеру

Сваки рекурзивни позив добија показивач на следећи карактер, па се базни случај достиже када тај показивач стигне до `'\0'`.

Овде не морамо да чувамо посебну локалну вредност пре рекурзивног `call`: после повратка нам треба само дужина остатка ниске, на коју додајемо `1`.

## Превођење

```sh
g++ main.cpp duzina_niske_rekurzivno.s
```

## Покретање

```sh
./a.out
```

Пример интеракције:

```text
rekurzija
9
```

## На шта треба обратити пажњу

- базни случај је `*s == '\0'`, када више нема карактера за бројање
- рекурзивни позив добија адресу следећег карактера, односно `s + 1`
- овде не чувамо посебну локалну вредност преко рекурзивног `call`; после повратка само додајемо `1`
