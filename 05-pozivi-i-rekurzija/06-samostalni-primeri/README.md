# Самостални мини-примери

Ови задаци служе као кратка допуна главним примерима из недеље 5. Намерно су краћи од главних примера и могу да се раде као вежбе након проласка кроз главни део материјала.

## Садржај

- [Испиши више пута](./01-ispisi_puta/README.md)
- [Рекурзивни степен](./02-stepen_rekurzivno/README.md)
- [Рекурзивна сума низа](./03-zbir_niza_rekurzivno/README.md)
- [Преброј преко predicate функције](./04-prebroj_predikat/README.md)
- [Рекурзивна дужина ниске](./05-duzina_niske_rekurzivno/README.md)

## Препоручени редослед

1. Почните од [Испиши више пута](./01-ispisi_puta/README.md), јер је то најкраћи пример са више позива `puts` из исте функције.
2. Наставите са [Рекурзивним степеном](./02-stepen_rekurzivno/README.md), који је природан наставак рекурзивног факторијела.
3. Потом урадите [Рекурзивну суму низа](./03-zbir_niza_rekurzivno/README.md), јер комбинује рекурзију и адресну аритметику над низом.
4. После тога пробајте [Преброј преко predicate функције](./04-prebroj_predikat/README.md), јер се враћа на индиректан `call`, али без ране завршнице.
5. На крају погледајте [Рекурзивну дужину ниске](./05-duzina_niske_rekurzivno/README.md), јер је то кратак пример рекурзије над показивачем на карактере.

## Напомена

Овде су задаци краћи и намерно остављају више простора да сами испратите шта се дешава са стеком, аргументима и повратним вредностима.

Код нерекурзивних примера пратите које вредности морају да преживе више `call` инструкција. Код рекурзивних примера гледајте базни случај, рекурзивни позив и шта се дешава при повратку.

| пример | шта увежбава |
| --- | --- |
| `ispisi_puta` | више библиотечких позива из исте функције |
| `stepen_rekurzivno` | рекурзију са сачуваном вредношћу после повратка |
| `zbir_niza_rekurzivno` | рекурзију уз померање показивача кроз низ |
| `prebroj_predikat` | индиректан `call` без ране завршнице |
| `duzina_niske_rekurzivno` | рекурзију над показивачем на карактере |
