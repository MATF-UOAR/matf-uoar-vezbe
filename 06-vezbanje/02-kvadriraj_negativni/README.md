# Квадрирај негативни
У асемблеру, имплементирати функцију која квадрира све негативне елементе низа целих бројева, као и С програм који је позива. Аргументи
функције су адреса првог елемента низа и број елемената.

## Пример
```
6
3 4 -1 2 -5 3
3 4 1 2 25 3
```
## Превођење
```
g++ main.cpp kvadriraj_negativni.s
```
## Покретање
```
./a.out
```
