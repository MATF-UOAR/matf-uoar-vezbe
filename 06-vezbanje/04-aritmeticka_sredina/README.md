# Аритметичка средина
У асемблеру, имплеменитрати функцију која рачуна аритметичку средину низа, као и С програм који је позива. Аргументи функције су
показивач на први елемент низа и број елемената низа.
## Пример
```
6
1 2 3 4 5 6
1 2 3 16 25 36
```
## Покретање
```
g++ main.cpp aritmeticka_sredina.s
```
