# Већи од аритметичке средине
У асемблеру, имплементирати функцију која квадрира све елементе низа који су већи од његове аритметичке средине, као и С функцију која је позива.
Дозвољено је користити функцију из претходног задатка за рачунање аритметичке средине.

## Пример
```
5
1 2 3 4 5
1 2 3 16 25
```
## Превођење
```
g++ main.cpp aritmeticka_sredina.s veci_od_aritmeticke_sredine.s
```
## Покретање
```
./a.out
```
