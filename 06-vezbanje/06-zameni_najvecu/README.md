# Замени највећу цифру
У асемблеру, имплементирати функцију кора враћа број који се добија када се у броју `n`
сва појављивања његове највеће цифре замене цифром `c` , као и С програм који је позива.
Можете користити функцију која налази највећу цифру броја (из једног од претходних задатака) као помоћну.
## Пример
```
297693 4
247643
```
## Покретање
```
g++ main.cpp najveca_cifra.s zameni_najvecu.s
```
