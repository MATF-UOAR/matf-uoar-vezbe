# Припада фибоначију
У асемблеру, имплементирајте функцију која проверава да ли дат број припада фибоначијевом низу и ако припада враћа његов индекс у датом низу.
У случају да је број 1, потребно је вратити број 1.Ако број не припада низу потребно је вратити -1.  Такође је потребно написати С програм који позива ту функцију.

## Пример
```
55
indeks: 10
```
## Превођење
```
g++ main.cpp pripada_fibonaciju.s
```
## Покретање
```
./a.out
```
