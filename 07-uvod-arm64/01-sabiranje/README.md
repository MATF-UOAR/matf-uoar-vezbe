# Сабирање

Ово је први ARM64 пример у недељи. Намерно је исти као први `x86-64` пример из прве недеље: функција прима два `int` аргумента и враћа њихов збир.

## Шта програм ради

Програм из `main.cpp` учитава два цела броја, позива функцију `saberi` и исписује резултат.

Референтна C++ верзија функције је:

```cpp
int saberi(int a, int b) {
    return a + b;
}
```

## Датотеке

- `main.cpp` садржи C++ код који позива функцију `saberi`
- `saberi.s` је минимална ARM64 leaf функција
- `saberi-sa-stek-okvirom.s` је дужа верзија која прави стек оквир и чува аргументе у меморији

## Веза са x86-64 примером

На `x86-64` прва два `int` аргумента стижу у `edi` и `esi`, а повратна вредност иде у `eax`.

На ARM64 прва два `int` аргумента стижу у `w0` и `w1`, а повратна вредност такође иде у `w0`.

Зато је минимална функција врло кратка:

```asm
saberi:
    add w0, w0, w1
    ret
```

Инструкција `add w0, w0, w1` сабира аргументе и резултат одмах оставља у регистру за повратну вредност.

## Зашто постоји верзија са стек оквиром

Функцији `saberi` стек није потребан, јер не користи локалне променљиве и не позива друге функције. Ипак, верзија `saberi-sa-stek-okvirom.s` показује стандардни ARM64 облик чувања `fp` и `lr`. Регистри `fp` и `lr` су само читљивији називи за `x29` и `x30`, па би и тај запис био исправан:

```asm
stp fp, lr, [sp, #-16]!
mov fp, sp
sub sp, sp, #16

// telo funkcije

mov sp, fp
ldp fp, lr, [sp], #16
ret
```

Ово ће бити важно у примеру `Hello world`, јер `main` позива `puts`, па мора да сачува повратну адресу из `lr`.

## Превођење

Минимална верзија:

```sh
aarch64-linux-gnu-g++ main.cpp saberi.s -o saberi
```

Верзија са стек оквиром:

```sh
aarch64-linux-gnu-g++ main.cpp saberi-sa-stek-okvirom.s -o saberi
```

## Покретање

```sh
qemu-aarch64 ./saberi
```

Пример интеракције:

```text
3 5
8
```

## На шта треба обратити пажњу

- `w0` има двоструку улогу: на улазу је први аргумент, а на излазу је повратна вредност
- `w1` је други `int` аргумент
- leaf функција која не позива друге функције може да се заврши само са `ret`
- за 64-битне вредности користили бисмо `x0`, `x1`, ... уместо `w0`, `w1`, ...
