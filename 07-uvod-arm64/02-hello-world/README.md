# Hello world

Овај пример долази после сабирања, као и у првој недељи, јер уводи више нових идеја:

- ниску смештену у секцији `.rodata`
- рачунање адресе симбола
- позив библиотечке функције `puts`
- чување `fp` и `lr` на стеку

## Датотеке

- `hello.cpp` је референтна C++ верзија програма
- `hello.s` је ARM64 асемблерска имплементација функције `main`

## Шта је ново у односу на сабирање

Функција `saberi` је leaf функција: не позива никога. Овде `main` позива `puts`, па мора да сачува повратну адресу.

На ARM64 инструкција `bl puts` уписује повратну адресу у `x30`, односно `lr`. Ако наша функција позива другу функцију, морамо да сачувамо `lr` пре позива, иначе не бисмо знали где да се вратимо на крају `main` функције.

Зато пример почиње овако:

```asm
stp x29, x30, [sp, -16]!
mov x29, sp
```

и завршава се симетрично:

```asm
ldp x29, x30, [sp], 16
ret
```

## Адреса ниске

Ниска је у секцији `.rodata`:

```asm
msg: .asciz "Hello world!"
```

Функција `puts` очекује адресу ниске као први аргумент. На ARM64 први аргумент иде у `x0`, па адресу припремамо овако:

```asm
adrp x0, msg
add x0, x0, :lo12:msg
```

То је ARM64 облик онога што смо на `x86-64` писали као:

```asm
lea rdi, [rip+msg]
```

## Превођење

Референтна C++ верзија:

```sh
aarch64-linux-gnu-g++ hello.cpp -o hello-cpp
```

Асемблерска верзија:

```sh
aarch64-linux-gnu-g++ hello.s -o hello
```

## Покретање

```sh
qemu-aarch64 ./hello
```

Очекивани излаз је:

```text
Hello world!
```

## На шта треба обратити пажњу

- `bl` је ARM64 позив функције
- `ret` се враћа на адресу из `lr`, односно `x30`
- `puts` сам додаје нови ред на крају исписа
- `w0` на крају постављамо на `0`, јер је то повратна вредност функције `main`
