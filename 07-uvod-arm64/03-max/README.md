# Максимум два броја

Овај пример показује како се познати `x86-64` образац `cmp` + условни скок чита на ARM64.

## Шта програм ради

Програм учитава два `int` броја, позива функцију `max` и исписује већи од та два броја.

Референтна C++ верзија функције је:

```cpp
int max(int x, int y) {
    if (x >= y) {
        return x;
    }
    return y;
}
```

## Датотеке

- `main.cpp` чита два броја и позива `max`
- `max.s` садржи ARM64 имплементацију функције

## Веза са x86-64 примером

На `x86-64` смо имали овакав облик:

```asm
cmp edi, esi
jle else_grana
```

На ARM64 аргументи су у `w0` и `w1`, а условни скокови имају облик `b.<услов>`:

```asm
cmp w0, w1
b.ge kraj
mov w0, w1

kraj:
ret
```

Овде је логика следећа:

- ако је `w0 >= w1`, први аргумент је већ у регистру за повратну вредност, па идемо на крај
- у супротном, већи је други аргумент, па га уписујемо у `w0`
- `ret` враћа вредност из `w0`

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp max.s -o max
```

## Покретање

```sh
qemu-aarch64 ./max
```

Пример интеракције:

```text
4 9
max(4, 9) = 9
```

## На шта треба обратити пажњу

- `cmp w0, w1` пореди два `int` аргумента
- `b.ge` је условни скок за означено поређење `>=`
- није потребан стек оквир, јер је `max` leaf функција
- повратна вредност мора остати у `w0`
