# Одузимање

Ово је најкраћи самостални пример после `saberi`. Функција прима два `int` аргумента и враћа `a - b`.

Референтна C++ верзија је:

```cpp
int oduzmi(int a, int b) {
    return a - b;
}
```

## Шта треба посматрати

- `a` стиже у `w0`
- `b` стиже у `w1`
- резултат треба да остане у `w0`
- ARM64 инструкција `sub w0, w0, w1` значи `w0 = w0 - w1`

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp oduzmi.s -o oduzmi
```

## Покретање

```sh
qemu-aarch64 ./oduzmi
```

Пример интеракције:

```text
10 4
6
```
