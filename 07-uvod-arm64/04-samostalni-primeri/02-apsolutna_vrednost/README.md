# Апсолутна вредност

Овај пример је први самостални ARM64 пример са условним скоком. Функција враћа апсолутну вредност броја.

Референтна C++ верзија је:

```cpp
int apsolutna_vrednost(int x) {
    if (x < 0) {
        return -x;
    }
    return x;
}
```

## Шта треба посматрати

Аргумент `x` стиже у `w0`, а повратна вредност такође треба да буде у `w0`.

Образац је:

```asm
cmp w0, #0
b.ge kraj
neg w0, w0
```

Ако је `x >= 0`, вредност је већ добра и скаче се на крај. Ако није, инструкција `neg` мења знак вредности у `w0`.

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp apsolutna_vrednost.s -o apsolutna_vrednost
```

## Покретање

```sh
qemu-aarch64 ./apsolutna_vrednost
```

Пример интеракције:

```text
-7
7
```
