# Максимум три броја

Ово је проширење примера `max` на три аргумента. Функција враћа највећи од бројева `x`, `y` и `z`.

Референтна C++ верзија је:

```cpp
int max3(int x, int y, int z) {
    int rezultat = x;
    if (y > rezultat) {
        rezultat = y;
    }
    if (z > rezultat) {
        rezultat = z;
    }
    return rezultat;
}
```

## Шта треба посматрати

- `x` стиже у `w0`
- `y` стиже у `w1`
- `z` стиже у `w2`
- `w0` на крају мора да садржи максимум

Пошто је `x` већ у `w0`, он је почетни кандидат за максимум. Затим га поредимо са `y`, па са `z`.

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp max3.s -o max3
```

## Покретање

```sh
qemu-aarch64 ./max3
```

Пример интеракције:

```text
4 9 2
9
```
