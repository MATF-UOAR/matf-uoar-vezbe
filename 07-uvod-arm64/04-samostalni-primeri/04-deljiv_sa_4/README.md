# Дељивост са 4

Овај пример проверава да ли је број дељив са `4`. Функција враћа `1` ако јесте, а `0` ако није.

Референтна C++ верзија је:

```cpp
int deljiv_sa_4(int x) {
    if (x % 4 == 0) {
        return 1;
    }
    return 0;
}
```

## Шта треба посматрати

За дељивост са `4` није неопходно да користимо дељење. Довољно је да проверимо два најнижа бита:

```asm
and w1, w0, #3
```

Ако је резултат `0`, број је дељив са `4`. Зато после тога следи познати образац:

```asm
cmp w1, #0
b.ne kraj
```

Овде је `#3` битмаска `0b11`, односно маска која оставља само два најнижа бита.

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp deljiv_sa_4.s -o deljiv_sa_4
```

## Покретање

```sh
qemu-aarch64 ./deljiv_sa_4
```

Пример интеракције:

```text
12
Deljiv je
```
