# Самостални примери

Ови примери служе да се познати кратки `x86-64` задаци преведу у ARM64. Сви су намерно мали: циљ је да се утврде регистри `w0`, `w1`, `w2`, повратна вредност у `w0`, и образац `cmp` + `b.<услов>`.

- [Одузимање](./01-oduzmi/README.md)
- [Апсолутна вредност](./02-apsolutna_vrednost/README.md)
- [Максимум три броја](./03-max3/README.md)
- [Дељивост са 4](./04-deljiv_sa_4/README.md)

## Препоручени редослед

1. Прво урадите [Одузимање](./01-oduzmi/README.md), јер је најближе примеру `saberi`.
2. Затим [Апсолутну вредност](./02-apsolutna_vrednost/README.md), јер уводи једно једноставно гранање.
3. После тога [Максимум три броја](./03-max3/README.md), који понавља исти образац два пута.
4. На крају [Дељивост са 4](./04-deljiv_sa_4/README.md), где се услов добија битовском операцијом.

## Како их читати

Код сваког примера прво погледајте потпис функције у `main.cpp`, па на основу њега одредите где су аргументи:

- први `int` је у `w0`
- други `int` је у `w1`
- трећи `int` је у `w2`
- повратна вредност је у `w0`

После тога је лакше читати сам ARM64 код, јер сваки пример само помера вредности кроз ове регистре.
