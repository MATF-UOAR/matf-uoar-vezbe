# Факторијел

Ово је први ARM64 пример са петљом у овој недељи. Функција `faktorijel` прима један `unsigned` број и враћа `n!`.

Референтна C++ верзија итеративне функције је:

```cpp
unsigned faktorijel(unsigned n) {
    unsigned rezultat = 1;
    for (unsigned i = 1; i <= n; i++) {
        rezultat *= i;
    }
    return rezultat;
}
```

## Шта треба посматрати у асемблеру

Аргумент `n` стиже у `w0`, али нам је `w0` потребан и као регистар за повратну вредност. Зато га на почетку копирамо у `w2`, а у `w0` постављамо акумулатор:

```asm
mov w2, w0
mov w0, #1
mov w1, #1
```

Услов `i <= n` записан је као излазак из петље када је `i > n`:

```asm
cmp w1, w2
b.hi kraj_petlje
```

Пошто су вредности `unsigned`, користимо неозначени услов `b.hi`.

Само множење радимо инструкцијом `mul`:

```asm
mul w0, w0, w1
```

Ова инструкција задржава доњих 32 бита производа када радимо са `w` регистрима. За тај доњи део резултата нема разлике између означеног и неозначеног множења. Разлика постаје важна када нам треба виша половина производа: за неозначене вредности постоји `umulh`, а за означене `smulh`.

## Рекурзивна варијанта

У директоријуму постоји и `faktorijel_rekurzivno.s`. Она није главни пример за ову недељу, али је корисна као поређење са каснијим примерима позива и рекурзије. Обе датотеке дефинишу исту функцију `faktorijel`, па се при превођењу бира једна од њих.

## Датотеке

- `main.cpp` чита број и исписује `n!`
- `faktorijel.s` садржи итеративну ARM64 имплементацију
- `faktorijel_rekurzivno.s` садржи рекурзивну варијанту исте функције

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp faktorijel.s -o faktorijel
```

Рекурзивна варијанта:

```sh
aarch64-linux-gnu-g++ main.cpp faktorijel_rekurzivno.s -o faktorijel
```

## Покретање

```sh
qemu-aarch64 ./faktorijel
```

Пример интеракције:

```text
5
5! = 120
```

## На шта треба обратити пажњу

- `0!` је `1`, па акумулатор креће од `1`
- `mul w0, w0, w1` множи тренутни резултат бројачем петље
- итеративна верзија је leaf функција и зато јој не треба стек оквир
