# НЗД

Овај пример преводи Еуклидов алгоритам на ARM64 и показује како се `while` петља комбинује са неозначеним дељењем.

## Шта програм ради

Програм учитава два `unsigned` броја и исписује њихов највећи заједнички делилац.

Референтна C++ функција је:

```cpp
unsigned NZD(unsigned a, unsigned b) {
    while (b != 0) {
        unsigned r = a % b;
        a = b;
        b = r;
    }
    return a;
}
```

## Шта треба посматрати у асемблеру

Услов петље проверавамо на почетку:

```asm
while_petlja:
    cmp w1, #0
    b.eq kraj_petlje
```

На ARM64 инструкција `udiv` враћа само количник. То је варијанта за неозначено дељење и зато одговара типу `unsigned`; за означено дељење користи се `sdiv`. Остатак добијамо тако што од старог `a` одузмемо `kolicnik * b`:

```asm
udiv w2, w0, w1
msub w3, w2, w1, w0
```

После тога се аргументи ротирају као у C++ коду:

```asm
mov w0, w1
mov w1, w3
```

## Датотеке

- `main.cpp` чита два броја и позива `NZD`
- `nzd.s` садржи ARM64 имплементацију функције `NZD`

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp nzd.s -o nzd
```

## Покретање

```sh
qemu-aarch64 ./nzd
```

Пример интеракције:

```text
12 18
NZD(12, 18) = 6
```

## На шта треба обратити пажњу

- први аргумент је у `w0`, други у `w1`
- `udiv` је неозначено дељење, па одговара типу `unsigned`
- `msub` овде служи као ARM64 начин да добијемо остатак при дељењу
