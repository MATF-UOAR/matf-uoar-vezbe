# Ојлер

Ово је први пример у ARM64 делу у ком једна асемблерска функција позива другу асемблерску функцију унутар петље.

## Шта програм ради

Програм учитава `unsigned n` и исписује вредност Ојлерове функције, односно број вредности `i` за које важи `1 <= i < n` и `nzd(i, n) = 1`.

Референтна C++ функција је:

```cpp
unsigned ojler(unsigned n) {
    unsigned br_up = 0;
    for (unsigned i = 1; i < n; i++) {
        if (nzd(i, n) == 1) {
            br_up++;
        }
    }
    return br_up;
}
```

## Шта треба посматрати у асемблеру

Петља користи три вредности:

```asm
mov w1, w0
mov w2, #0
mov w3, #1
```

Овде је `w1` број `n`, `w2` бројач узајамно простих бројева, а `w3` индекс петље. Услов `i < n` записан је као излазак када важи `i >= n`:

```asm
cmp w3, w1
b.hs kraj_petlje
```

## Позив функције

Пре првог `bl` важно је да знамо основни ARM64 договор за целобројне аргументе:

| Група | Регистри | Практично правило |
| --- | --- | --- |
| Аргументи и повратна вредност | `x0`-`x7`, односно `w0`-`w7` за 32-битне вредности | Први аргументи иду редом у ове регистре, а повратна вредност се враћа у `x0` или `w0`. |
| `caller-saved` | `x0`-`x17` | Ако су нам вредности из ових регистара потребне после `bl`, функција која позива мора да их сачува. |
| `callee-saved` | `x19`-`x28`, `fp`/`x29`, `sp` | Ако их позвана функција користи, мора да их врати на старе вредности пре `ret`. |

Регистар `x18` зависи од платформе, па га у овим примерима не користимо као место за чување вредности.

Инструкција `bl` уписује повратну адресу у `lr`/`x30`. Зато функција `ojler`, пошто и сама позива другу функцију, на почетку чува `fp` и `lr`:

```asm
stp fp, lr, [sp, #-16]!
mov fp, sp
```

За позив `nzd(i, n)` први аргумент треба да буде у `w0`, а други у `w1`. У нашем коду је `n` већ у `w1`, па пред позив само премештамо `i` у `w0`:

```asm
mov w0, w3
bl nzd
```

Пре позива `nzd`, вредности из `w1`, `w2` и `w3` чувамо на стеку, јер позвана функција сме да их препише:

```asm
sub sp, sp, #16
str w1, [sp]
str w2, [sp, #4]
str w3, [sp, #8]

mov w0, w3
bl nzd
```

После повратка их враћамо и настављамо петљу. Простор на стеку је `16` бајтова да би `sp` остао поравнат на `16` пре `bl`.

## Датотеке

- `main.cpp` чита број и позива `ojler`
- `ojler.s` садржи ARM64 имплементацију функције `ojler`
- `nzd.s` садржи помоћну ARM64 функцију `nzd`

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp ojler.s nzd.s -o ojler
```

## Покретање

```sh
qemu-aarch64 ./ojler
```

Пример интеракције:

```text
87
ojler(87) = 56
```

## На шта треба обратити пажњу

- функција која ради `bl` мора да сачува `lr`, па `ojler` има стек оквир
- вредности које су потребне после позива `nzd` морају да се сачувају пре `bl`
- услов `b.hs` одговара неозначеном поређењу `i >= n`
