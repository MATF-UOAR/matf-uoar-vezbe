# Прост број

Овај пример проверава да ли је број прост. Добар је као додатна вежба за `for` петљу, рани излазак из функције и рачунање остатка помоћу `udiv` и `msub`.

У директоријуму постоји и друга варијанта која користи претходно написану Ојлерову функцију.

## Шта програм ради

Програм учитава `unsigned n` и исписује да ли је број прост.

Референтна C++ функција је:

```cpp
unsigned prost(unsigned n) {
    if (n < 2) {
        return 0;
    }

    for (unsigned d = 2; d < n; d++) {
        if (n % d == 0) {
            return 0;
        }
    }

    return 1;
}
```

## Шта треба посматрати у асемблеру

Бројеви `0` и `1` нису прости, па њих одмах одвајамо:

```asm
cmp w0, #2
b.hs proveri_delioce

mov w0, #0
ret
```

Петља проверава делиоце `d` од `2` до `n - 1`. Услов `d < n` записан је као излазак из петље када је `d >= n`:

```asm
cmp w2, w1
b.hs jeste_prost
```

Као и у примеру `NZD`, остатак при дељењу добијамо преко количника:

```asm
udiv w3, w1, w2
msub w4, w3, w2, w1
```

Ако је остатак `0`, пронашли смо делилац и функција одмах враћа `0`:

```asm
cmp w4, #0
b.eq nije_prost
```

## Варијанта преко Ојлера

За `n > 1` важи да је број прост ако и само ако је `ojler(n) = n - 1`. Зато друга варијанта проверава услов:

```cpp
unsigned prost(unsigned n) {
    if (n < 2) {
        return 0;
    }

    return ojler(n) + 1 == n;
}
```

Пошто `prost_preko_ojlera.s` позива функцију `ojler`, мора да сачува `lr`, а мора да сачува и оригинално `n`, јер се повратна вредност из `ojler` враћа у `w0`:

```asm
sub sp, sp, #16
str w0, [sp]

bl ojler

ldr w1, [sp]
add sp, sp, #16
```

После позива пореди се `ojler(n) + 1` са сачуваним `n`:

```asm
add w0, w0, #1
cmp w0, w1
b.eq jeste_prost
```

## Датотеке

- `main.cpp` чита број и исписује да ли је прост
- `prost.s` садржи директну ARM64 имплементацију функције `prost`
- `prost_preko_ojlera.s` садржи варијанту која позива `ojler`

Обе `.s` датотеке дефинишу функцију `prost`, па се при превођењу бира једна од њих.

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp prost.s -o prost
```

Варијанта преко Ојлерове функције:

```sh
aarch64-linux-gnu-g++ main.cpp prost_preko_ojlera.s ../03-ojler/ojler.s ../03-ojler/nzd.s -o prost
```

## Покретање

```sh
qemu-aarch64 ./prost
```

Пример интеракције:

```text
17
Broj je prost
```

## На шта треба обратити пажњу

- директна варијанта `prost.s` је leaf функција и зато јој не треба стек оквир
- `b.hs` одговара неозначеном поређењу `d >= n`
- пример има рани излазак из тела петље када се пронађе делилац
- варијанта преко Ојлера није leaf функција, јер ради `bl ojler`
