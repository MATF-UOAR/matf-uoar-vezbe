# Secret

Овај пример има намерно неописно име функције, али сама функција ради познат поступак: сабира цифре броја све док резултат не постане једноцифрен.

## Шта програм ради

Програм учитава `unsigned n` и исписује резултат функције `secret`.

Референтна C++ функција је:

```cpp
unsigned secret(unsigned n) {
    while (n >= 10) {
        unsigned zbir = 0;
        while (n != 0) {
            zbir += n % 10;
            n /= 10;
        }
        n = zbir;
    }
    return n;
}
```

На пример, за `9875` први збир цифара је `29`, а затим је `2 + 9 = 11`, па `1 + 1 = 2`.

## Шта треба посматрати у асемблеру

Пример има две петље. Спољашња петља проверава да ли је број већ једноцифрен:

```asm
spoljasnja_petlja:
    cmp w0, #10
    b.lo kraj
```

Унутрашња петља издваја цифре једну по једну. Као у примеру `NZD`, остатак се добија комбинацијом `udiv` и `msub`:

```asm
udiv w2, w0, w10
msub w3, w2, w10, w0

mov w0, w2
add w1, w1, w3
```

Регистар `w10` садржи константу `10`, `w1` је тренутни збир цифара, `w2` је количник, а `w3` је последња цифра.

## Датотеке

- `main.cpp` чита број и позива `secret`
- `secret.s` садржи ARM64 имплементацију функције

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp secret.s -o secret
```

## Покретање

```sh
qemu-aarch64 ./secret
```

Пример интеракције:

```text
9875
secret(9875) = 2
```

## На шта треба обратити пажњу

- спољашња петља се извршава док је `n >= 10`
- унутрашња петља је исти образац као збир цифара, само у ARM64 облику
- функција не позива друге функције, па јој не треба стек оквир
