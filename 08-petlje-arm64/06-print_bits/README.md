# Испис битова

Овај пример исписује бинарни запис броја без водећих нула. За `0` се исписује једна нула.

## Шта програм ради

Програм учитава `unsigned n` и позива функцију `print_bits`, која исписује битове броја помоћу библиотечке функције `putchar`.

Референтна C++ верзија функције могла би да изгледа овако:

```cpp
void print_bits(unsigned n) {
    if (n == 0) {
        putchar('0');
        return;
    }

    unsigned maska = 1u << 31;
    while (maska > n) {
        maska >>= 1;
    }

    while (maska != 0) {
        putchar((n & maska) == 0 ? '0' : '1');
        maska >>= 1;
    }
}
```

## Шта треба посматрати у асемблеру

Маска почиње од највишег бита 32-битног броја:

```asm
mov w1, #1
lsl w1, w1, #31
```

Док је маска већа од броја, прескачемо водеће нуле:

```asm
cmp w1, w0
b.hi nastavak
```

Када треба да испишемо један бит, проверавамо га инструкцијом `tst`:

```asm
tst w0, w1
csel w0, w2, w3, eq
bl putchar
```

`w2` садржи карактер `'0'`, а `w3` карактер `'1'`. Инструкција `csel` бира шта иде у `w0`, односно шта ће бити аргумент за `putchar`. Као и код других позива функција, први аргумент иде у `w0`, а повратна вредност би такође дошла у `w0`.

## Чување вредности пре `putchar`

Пошто су `w0` и `w1` делови `caller-saved` регистара, `putchar` сме да их препише. Зато пре позива чувамо број и маску на стеку:

```asm
sub sp, sp, #16
str w0, [sp]
str w1, [sp, #4]
```

После `bl putchar` вредности се враћају и петља се наставља.

## Датотеке

- `main.cpp` чита број и позива `print_bits`
- `print_bits.s` садржи ARM64 имплементацију функције

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp print_bits.s -o print_bits
```

## Покретање

```sh
qemu-aarch64 ./print_bits
```

Пример интеракције:

```text
13
1101
```

## На шта треба обратити пажњу

- `tst w0, w1` проверава да ли је тренутни бит постављен
- `csel` омогућава избор између `'0'` и `'1'` без додатног гранања
- стек остаје поравнат на `16` бајтова пре позива `putchar`
