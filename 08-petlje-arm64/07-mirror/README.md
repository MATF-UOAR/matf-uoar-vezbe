# Огледање битова

Овај пример обрће редослед значајних битова броја. Водеће нуле се не узимају у обзир.

## Шта програм ради

Програм учитава `unsigned n`, исписује његов бинарни запис, затим позива `mirror` и исписује бинарни запис добијеног броја.

Референтна C++ функција је:

```cpp
unsigned mirror(unsigned n) {
    unsigned rezultat = 0;
    while (n != 0) {
        rezultat <<= 1;
        if (n & 1) {
            rezultat++;
        }
        n >>= 1;
    }
    return rezultat;
}
```

На пример, `13` је бинарно `1101`, а после огледања значајних битова добија се `1011`, односно `11`.

## Шта треба посматрати у асемблеру

Резултат се помера улево у свакој итерацији:

```asm
lsl w1, w1, #1
```

Последњи бит улазног броја проверавамо помоћу `tst`:

```asm
tst w0, #1
b.eq preskoci_jedinicu
add w1, w1, #1
```

На крају итерације улазни број померамо удесно:

```asm
lsr w0, w0, #1
```

Када `w0` постане `0`, у `w1` је добијени резултат и пребацујемо га у `w0` као повратну вредност.

## Датотеке

- `main.cpp` чита број, исписује битове пре и после позива `mirror`
- `mirror.s` садржи ARM64 имплементацију функције `mirror`
- `print_bits.s` је помоћна функција за испис бинарног записа

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp mirror.s print_bits.s -o mirror
```

## Покретање

```sh
qemu-aarch64 ./mirror
```

Пример интеракције:

```text
13
1101
1011
```

## На шта треба обратити пажњу

- `mirror` је leaf функција и не користи стек
- `print_bits` се преводи заједно са примером зато што `main.cpp` користи обе функције
- број `0` остаје `0`, па се пре и после огледања исписује `0`
