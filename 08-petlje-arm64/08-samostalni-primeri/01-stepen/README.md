# Степен

Овај пример утврђује исту идеју као `faktorijel`, али сада функција има два аргумента: базу и број понављања.

Функција `stepen` враћа вредност `a^n` помоћу поновљеног множења.

Референтна C++ верзија функције је:

```cpp
unsigned stepen(unsigned a, unsigned n) {
    unsigned rezultat = 1;
    for (unsigned i = 0; i < n; i++) {
        rezultat *= a;
    }
    return rezultat;
}
```

## Шта треба посматрати у асемблеру

Аргументи стижу у `w0` и `w1`, али `w0` користимо и за повратну вредност. Зато базу чувамо у `w2`, а у `w0` постављамо акумулатор:

```asm
mov w2, w0
mov w0, #1
mov w3, #0
```

Услов `i < n` записан је као излазак када је `i >= n`:

```asm
cmp w3, w1
b.hs kraj_petlje
```

## Датотеке

- `main.cpp` чита базу и експонент и исписује резултат
- `stepen.s` садржи ARM64 имплементацију функције `stepen`

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp stepen.s -o stepen
```

## Покретање

```sh
qemu-aarch64 ./stepen
```

Пример интеракције:

```text
3 4
3^4 = 81
```

## На шта треба обратити пажњу

- `a^0` је `1`, па акумулатор креће од `1`
- `mul w0, w0, w2` множи тренутни резултат базом
- функција је leaf функција и зато јој не треба стек оквир
