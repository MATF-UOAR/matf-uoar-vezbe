# Збир цифара

Овај пример спаја `while` петљу са ARM64 начином рачунања остатка при дељењу.

Функција `zbir_cifara` враћа збир свих цифара броја `n`.

Референтна C++ верзија функције је:

```cpp
unsigned zbir_cifara(unsigned n) {
    unsigned zbir = 0;
    while (n != 0) {
        zbir += n % 10;
        n /= 10;
    }
    return zbir;
}
```

## Шта треба посматрати у асемблеру

Делилац `10` чувамо у посебном регистру:

```asm
mov w10, #10
```

У свакој итерацији количник добијамо инструкцијом `udiv`, а остатак инструкцијом `msub`:

```asm
udiv w2, w0, w10
msub w3, w2, w10, w0
```

После тога остатак додајемо на збир, а број замењујемо количником:

```asm
add w1, w1, w3
mov w0, w2
```

## Датотеке

- `main.cpp` чита број и исписује збир његових цифара
- `zbir_cifara.s` садржи ARM64 имплементацију функције

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp zbir_cifara.s -o zbir_cifara
```

## Покретање

```sh
qemu-aarch64 ./zbir_cifara
```

Пример интеракције:

```text
50271
Zbir cifara: 15
```

## На шта треба обратити пажњу

- за `n = 0` петља се не извршава и резултат остаје `0`
- `w0` постепено постаје `n / 10`, па се не чува оригинални број
- образац `udiv` + `msub` је исти као у примерима `NZD`, `secret` и `prost`
