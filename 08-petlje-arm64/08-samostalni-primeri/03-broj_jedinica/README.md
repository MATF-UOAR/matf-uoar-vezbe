# Број јединица

Овај пример броји колико јединица има у бинарном запису броја.

Функција `broj_jedinica` враћа број постављених битова у `unsigned` броју `n`.

Референтна C++ верзија функције је:

```cpp
unsigned broj_jedinica(unsigned n) {
    unsigned broj = 0;
    while (n != 0) {
        if (n & 1) {
            broj++;
        }
        n >>= 1;
    }
    return broj;
}
```

## Шта треба посматрати у асемблеру

Последњи бит проверавамо инструкцијом `tst`:

```asm
tst w0, #1
b.eq preskoci
add w1, w1, #1
```

После провере број померамо удесно, па следећи бит долази на последњу позицију:

```asm
lsr w0, w0, #1
```

Петља се завршава када број постане `0`.

## Датотеке

- `main.cpp` чита број и исписује број јединица у бинарном запису
- `broj_jedinica.s` садржи ARM64 имплементацију функције

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp broj_jedinica.s -o broj_jedinica
```

## Покретање

```sh
qemu-aarch64 ./broj_jedinica
```

Пример интеракције:

```text
13
Broj jedinica: 3
```

## На шта треба обратити пажњу

- `13` је бинарно `1101`, па има три јединице
- `tst w0, #1` проверава само најнижи бит
- овај пример је близак примерима `print_bits` и `mirror`, али не позива `putchar`
