# Број делилаца

Овај пример комбинује петљу, остатак при дељењу и један једноставан услов унутар тела петље.

Функција `broj_delilaca` враћа број природних делилаца броја `n`.

Референтна C++ верзија функције је:

```cpp
unsigned broj_delilaca(unsigned n) {
    unsigned broj = 0;
    for (unsigned d = 1; d <= n; d++) {
        if (n % d == 0) {
            broj++;
        }
    }
    return broj;
}
```

## Шта треба посматрати у асемблеру

Оригинални број чувамо у `w1`, јер `w0` користимо као бројач делилаца:

```asm
mov w1, w0
mov w0, #0
mov w2, #1
```

Услов `d <= n` записан је као излазак када је `d > n`:

```asm
cmp w2, w1
b.hi kraj_petlje
```

Дељивост проверавамо преко остатка:

```asm
udiv w3, w1, w2
msub w4, w3, w2, w1

cmp w4, #0
b.ne nastavak
add w0, w0, #1
```

## Датотеке

- `main.cpp` чита број и исписује број његових делилаца
- `broj_delilaca.s` садржи ARM64 имплементацију функције

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp broj_delilaca.s -o broj_delilaca
```

## Покретање

```sh
qemu-aarch64 ./broj_delilaca
```

Пример интеракције:

```text
12
Broj delilaca: 6
```

## На шта треба обратити пажњу

- за `n = 0` петља се не извршава и функција враћа `0`
- `b.hi` одговара неозначеном услову `d > n`
- овај пример је намерно директан и пролази кроз све бројеве од `1` до `n`
