# НЗС

Овај пример је кратак наставак примера `ojler` и `prost_preko_ojlera`, јер једна асемблерска функција позива другу, а затим наставља рачунање над добијеним резултатом.

Функција `nzs` враћа најмањи заједнички садржалац бројева `a` и `b`.

Референтна C++ верзија функције је:

```cpp
unsigned nzd(unsigned a, unsigned b);

unsigned nzs(unsigned a, unsigned b) {
    unsigned d = nzd(a, b);
    if (d == 0) {
        return 0;
    }
    return a / d * b;
}
```

## Шта треба посматрати у асемблеру

Пошто `nzs` позива функцију `nzd`, на почетку чува `fp` и `lr`:

```asm
stp fp, lr, [sp, #-16]!
mov fp, sp
```

Аргументи `a` и `b` биће нам потребни и после позива, па их чувамо на стеку:

```asm
sub sp, sp, #16
str w0, [sp]
str w1, [sp, #4]

bl nzd
```

Ако је `nzd(a, b)` једнак `0`, оба броја су била `0`, па функција враћа `0`. У супротном користимо формулу `a / nzd(a, b) * b`:

```asm
mov w2, w0
ldr w3, [sp]
ldr w4, [sp, #4]

udiv w5, w3, w2
mul w0, w5, w4
```

## Датотеке

- `main.cpp` чита два броја и исписује њихов НЗС
- `nzs.s` садржи ARM64 имплементацију функције `nzs`
- `nzd.s` садржи помоћну ARM64 функцију `nzd`

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp nzs.s nzd.s -o nzs
```

## Покретање

```sh
qemu-aarch64 ./nzs
```

Пример интеракције:

```text
12 18
NZS(12, 18) = 36
```

## На шта треба обратити пажњу

- `nzs` није leaf функција, јер ради `bl nzd`
- пре `bl nzd` стек остаје поравнат на `16` бајтова
- посебно пазимо на случај `a = 0` и `b = 0`, да не бисмо делили нулом
