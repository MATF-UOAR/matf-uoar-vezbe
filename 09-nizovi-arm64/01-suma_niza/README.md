# Сума елемената низа

Ово је први пример у недељи. Функција пролази кроз низ `int` вредности и враћа њихов збир. У директоријуму постоје четири асемблерске верзије исте функције, да би се упоредили различити начини адресирања.

## Шта програм ради

Програм учитава дужину низа, затим његове елементе, позива `suma_niza` и исписује збир.

Референтна C++ функција је:

```cpp
int suma_niza(int* a, int n) {
    int suma = 0;
    for (int i = 0; i < n; i++) {
        suma += a[i];
    }
    return suma;
}
```

## Датотеке

- `main.cpp` чита низ и позива `suma_niza`
- `suma_v1.s` користи базну адресу, индекс и скалу
- `suma_v2.s` користи pre-index адресирање
- `suma_v3.s` користи post-index адресирање
- `suma_v4.s` користи post-index адресирање и број преосталих елемената, без посебног индекса

Све асемблерске датотеке дефинишу исту функцију `suma_niza`, па се при превођењу бира једна од њих.

## Шта треба посматрати у асемблеру

У првој верзији база низа је у `x0`, индекс је у `w3`, а елемент се чита овако:

```asm
ldr w4, [x0, x3, lsl #2]
```

Пошто је елемент типа `int`, величина елемента је `4` бајта. Зато `lsl #2` множи индекс са `4`.

Друга верзија помери показивач један елемент уназад:

```asm
sub x0, x0, #4
ldr w4, [x0, #4]!
```

Знак `!` значи да се ажурирана адреса уписује назад у `x0`. После читања `x0` већ показује на управо прочитани елемент.

Трећа верзија користи post-index облик:

```asm
ldr w4, [x0], #4
```

Прво се прочита елемент на адреси `x0`, а затим се `x0` помери за `4` бајта, на следећи елемент.

Четврта верзија задржава post-index читање, али избегава посебан индекс `i`. Уместо тога користи `w1` као број елемената који су остали:

```asm
cmp w1, #0
b.le kraj_petlje
ldr w3, [x0], #4
sub w1, w1, #1
```

Ова верзија је најближа идеји „читај следећи елемент док их има“.

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp suma_v1.s -o suma_niza
```

Остале верзије се преводе заменом имена асемблерске датотеке:

```sh
aarch64-linux-gnu-g++ main.cpp suma_v2.s -o suma_niza
aarch64-linux-gnu-g++ main.cpp suma_v3.s -o suma_niza
aarch64-linux-gnu-g++ main.cpp suma_v4.s -o suma_niza
```

## Покретање

```sh
qemu-aarch64 ./suma_niza
```

Пример интеракције:

```text
5
1 2 -3 4 5
9
```

## На шта треба обратити пажњу

- `w2` је акумулатор за суму
- у индексној верзији база остаје у `x0`, а мења се индекс
- у верзијама са померањем показивача мења се сама адреса у `x0`
- post-index облик је природан када низ читамо редом, елемент по елемент
- све верзије су leaf функције и зато им не треба стек оквир
