# Максимум низа

Овај пример задржава пролаз кроз низ из претходног задатка, али уместо збира одржава текући максимум.

## Шта програм ради

Програм учитава дужину низа, затим елементе, позива `max_element` и исписује највећу вредност.

Референтна C++ функција је:

```cpp
int max_element(int* a, int n) {
    int maksimum = a[0];
    for (int i = 1; i < n; i++) {
        if (a[i] > maksimum) {
            maksimum = a[i];
        }
    }
    return maksimum;
}
```

Подразумевамо да је `n > 0`, јер функција почетну вредност узима из `a[0]`.

## Датотеке

- `main.cpp` чита низ и позива `max_element`
- `max_v1.s` пролази кроз низ преко индекса
- `max_v2.s` пролази кроз низ померањем показивача

Обе асемблерске датотеке дефинишу исти симбол, па се преводи само једна верзија одједном.

## Шта треба посматрати у асемблеру

Прва верзија чита `a[0]` као почетни максимум, а затим креће од индекса `1`:

```asm
ldr w2, [x0]
mov w3, #1
```

У телу петље елемент се чита преко базе, индекса и величине елемента:

```asm
ldr w4, [x0, x3, lsl #2]
```

После поређења користи се `csel`, условни избор:

```asm
cmp w4, w2
csel w2, w4, w2, gt
```

Ако је нови елемент већи, у `w2` улази `w4`; у супротном `w2` остаје исти.

Друга верзија чита први елемент и одмах помера показивач:

```asm
ldr w2, [x0], #4
```

Затим свака итерација чита следећи елемент истим post-index обликом.

## Превођење

Верзија са индексом:

```sh
aarch64-linux-gnu-g++ main.cpp max_v1.s -o max_element
```

Верзија са померањем показивача:

```sh
aarch64-linux-gnu-g++ main.cpp max_v2.s -o max_element
```

## Покретање

```sh
qemu-aarch64 ./max_element
```

Пример интеракције:

```text
5
7 2 9 1 4
9
```

## На шта треба обратити пажњу

- почетни максимум је `a[0]`, па овај пример подразумева непразан низ
- `csel` избегава посебну грану за ажурирање максимума
- `gt` је означено поређење, јер су елементи типа `int`
- друга верзија је добар пример када бројач служи само да знамо колико је елемената остало
- обе верзије су leaf функције и зато им не треба стек оквир
