# Минимум низа `unsigned long` вредности

Овај пример је намерно сличан примеру са максимумом, али елементи низа више нису `int`, већ `unsigned long`. Зато се мења ширина регистара и величина корака кроз низ.

## Шта програм ради

Програм учитава дужину низа, затим `unsigned long` елементе, позива `min_element` и исписује најмању вредност.

Референтна C++ функција је:

```cpp
unsigned long min_element(unsigned long* a, int n) {
    unsigned long minimum = a[0];
    for (int i = 1; i < n; i++) {
        if (a[i] < minimum) {
            minimum = a[i];
        }
    }
    return minimum;
}
```

Подразумевамо да је `n > 0`, јер функција почетну вредност узима из `a[0]`.

## Датотеке

- `main.cpp` чита низ и позива `min_element`
- `min_v1.s` користи индексно адресирање
- `min_v2.s` користи post-index померање показивача

Обе асемблерске датотеке дефинишу исту функцију `min_element`, па се преводи само једна од њих.

## Шта треба посматрати у асемблеру

Пошто је повратна вредност типа `unsigned long`, резултат се враћа у `x0`, а текући минимум чувамо у `x2`.

У индексној верзији елемент се чита овако:

```asm
ldr x4, [x0, x3, lsl #3]
```

Овде је `lsl #3` множење индекса са `8`, јер један `unsigned long` има `8` бајтова.

Поређење је неозначено:

```asm
cmp x4, x2
csel x2, x4, x2, lo
```

Услов `lo` значи lower и користи се за неозначено поређење. То одговара типу `unsigned long`.

Друга верзија користи post-index облик са кораком `8`:

```asm
ldr x3, [x0], #8
```

После читања елемента показивач у `x0` већ показује на следећи `unsigned long`.

## Превођење

Верзија са индексом:

```sh
aarch64-linux-gnu-g++ main.cpp min_v1.s -o min_element
```

Верзија са померањем показивача:

```sh
aarch64-linux-gnu-g++ main.cpp min_v2.s -o min_element
```

## Покретање

```sh
qemu-aarch64 ./min_element
```

Пример интеракције:

```text
4
12 4 8 2
2
```

## На шта треба обратити пажњу

- за 64-битне елементе користимо `x` регистре
- величина елемента одређује скалу: `lsl #3` значи множење са `8`
- за `unsigned long` поређење користимо неозначене услове, овде `lo`
- и овај пример подразумева непразан низ
- обе верзије су leaf функције и зато им не треба стек оквир
