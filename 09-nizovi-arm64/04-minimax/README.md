# Минимум и максимум `short` вредности

Овај пример пролази кроз низ `short` вредности само једном, али израчунава две вредности: минимум и максимум. Пошто функција треба да врати два резултата, она их уписује кроз референце.

## Шта програм ради

Програм учитава дужину низа, затим елементе, позива `minimax` и исписује минимум и максимум.

Референтна C++ функција је:

```cpp
void minimax(short* a, int n, short& pmin, short& pmax) {
    short minimum = a[0];
    short maksimum = a[0];

    for (int i = 1; i < n; i++) {
        if (a[i] < minimum) {
            minimum = a[i];
        }
        if (a[i] > maksimum) {
            maksimum = a[i];
        }
    }

    pmin = minimum;
    pmax = maksimum;
}
```

Подразумевамо да је `n > 0`, јер функција почетне вредности узима из `a[0]`.

## Датотеке

- `main.cpp` чита низ, позива `minimax` и исписује добијене вредности
- `minimax.s` садржи ARM64 имплементацију функције

## Шта треба посматрати у асемблеру

Потпис функције је:

```cpp
void minimax(short* a, int n, short& pmin, short& pmax);
```

На нивоу позивне конвенције референце су адресе. Зато аргументи стижу овако:

- `x0` је адреса првог елемента низа
- `w1` је број елемената
- `x2` је адреса на коју треба уписати минимум
- `x3` је адреса на коју треба уписати максимум

Функција чита први елемент и користи га као обе почетне вредности:

```asm
ldrsh w4, [x0], #2
mov w5, w4
```

Инструкција `ldrsh` чита `short` широк `2` бајта и знаковно га проширује у
`w` регистар. Тако поређења исправно раде и за негативне вредности, док
померај `#2` води показивач на следећи елемент низа.

У петљи се сваки следећи елемент пореди са тренутним минимумом и максимумом:

```asm
ldrsh w6, [x0], #2
cmp w6, w4
csel w4, w6, w4, lt
cmp w6, w5
csel w5, w6, w5, gt
```

На крају се резултати уписују у меморију:

```asm
strh w4, [x2]
strh w5, [x3]
```

Функција зато нема значајну повратну вредност у `w0`; резултат је промена садржаја на адресама `x2` и `x3`.

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp minimax.s -o minimax
```

## Покретање

```sh
qemu-aarch64 ./minimax
```

Пример интеракције:

```text
5
7 2 9 1 4
1 9
```

## На шта треба обратити пажњу

- C++ референце у асемблер стижу као адресе
- `ldrsh` учитава двобајтни `short` и чува његов знак у `w` регистру
- `strh w4, [x2]` уписује двобајтни `short` на адресу резултата
- једним проласком кроз низ ажурирају се и минимум и максимум
- пример подразумева непразан низ
- функција је leaf функција и зато јој не треба стек оквир
