# Дужина ниске

Овај пример показује да је ниска низ бајтова који се завршава посебном вредношћу `0`, односно карактером `'\0'`. За разлику од претходних примера, функција не добија дужину као посебан аргумент, већ сама тражи крај ниске.

## Шта програм ради

Програм учитава једну реч, прослеђује адресу њеног C записа функцији `duzina_niske` и исписује број карактера пре завршног `'\0'`.

Референтна C++ функција је:

```cpp
int duzina_niske(const char* s) {
    int duzina = 0;
    while (s[duzina] != '\0') {
        duzina++;
    }
    return duzina;
}
```

## Датотеке

- `main.cpp` чита `std::string` и позива `duzina_niske` над `s.c_str()`
- `duzina_niske.s` садржи ARM64 имплементацију функције

## Шта треба посматрати у асемблеру

Адреса првог карактера стиже у `x0`. Пошто ће `w0` бити повратна вредност, базну адресу пребацујемо у `x1`, а у `w0` чувамо тренутну дужину:

```asm
mov x1, x0
mov w0, #0
```

Карактер читамо инструкцијом `ldrb`:

```asm
ldrb w2, [x1, x0]
```

Суфикс `b` значи да се чита један бајт. То одговара типу `char`. Пошто је елемент широк један бајт, индекс није потребно множити са `4` или `8`.

Крај ниске препознаје се поређењем са нулом:

```asm
cmp w2, #0
b.eq kraj
```

Када стигнемо до `'\0'`, у `w0` је број прочитаних карактера и то је повратна вредност функције.

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp duzina_niske.s -o duzina_niske
```

## Покретање

```sh
qemu-aarch64 ./duzina_niske
```

Пример интеракције:

```text
arm64
5
```

## На шта треба обратити пажњу

- ниска нема посебан аргумент за дужину; крај се налази по бајту вредности `0`
- `ldrb` чита један бајт и нула-проширује га у `w2`
- код ниске је величина елемента `1`, па адреса следећег карактера расте за један бајт
- `std::string::c_str()` даје адресу C ниске која се завршава са `'\0'`
- функција је leaf функција и зато јој не треба стек оквир
