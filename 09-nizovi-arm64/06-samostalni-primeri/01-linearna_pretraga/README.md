# Линеарна претрага

Овај пример тражи прво појављивање вредности у низу. Ако вредност постоји, функција враћа њен индекс; ако не постоји, враћа `-1`.

## Шта програм ради

Програм учитава дужину низа, елементе низа и вредност `x`, затим позива `linearna_pretraga` и исписује добијени индекс.

Референтна C++ функција је:

```cpp
int linearna_pretraga(int* a, int n, int x) {
    for (int i = 0; i < n; i++) {
        if (a[i] == x) {
            return i;
        }
    }
    return -1;
}
```

## Шта треба посматрати у асемблеру

Аргументи стижу у:

- `x0`: адреса првог елемента
- `w1`: број елемената
- `w2`: тражена вредност

Индекс `i` чувамо у `w3`, а елемент читамо преко базе, индекса и скале:

```asm
ldr w4, [x0, x3, lsl #2]
```

Када је елемент једнак траженој вредности, одмах излазимо из функције:

```asm
cmp w4, w2
b.eq pronadjen
```

Ако петља стигне до краја, у `w0` уписујемо `-1`.

## Датотеке

- `main.cpp` чита низ, тражену вредност и позива `linearna_pretraga`
- `linearna_pretraga.s` садржи ARM64 имплементацију функције

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp linearna_pretraga.s -o linearna_pretraga
```

## Покретање

```sh
qemu-aarch64 ./linearna_pretraga
```

Пример интеракције:

```text
5
7 2 9 1 4
9
2
```

## На шта треба обратити пажњу

- ово је leaf функција и зато јој не треба стек оквир
- повратна вредност је индекс у `w0`
- `-1` је договор да тражена вредност није пронађена
- претрага не захтева да низ буде сортиран
