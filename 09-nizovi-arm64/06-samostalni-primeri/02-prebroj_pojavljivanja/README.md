# Број појављивања

Овај пример броји колико пута се вредност `x` појављује у низу. За разлику од линеарне претраге, не излазимо из петље када први пут нађемо `x`, већ морамо да прођемо кроз цео низ.

## Шта програм ради

Програм учитава дужину низа, елементе низа и вредност `x`, затим позива `prebroj_pojavljivanja` и исписује број појављивања.

Референтна C++ функција је:

```cpp
int prebroj_pojavljivanja(int* a, int n, int x) {
    int broj = 0;
    for (int i = 0; i < n; i++) {
        if (a[i] == x) {
            broj++;
        }
    }
    return broj;
}
```

## Шта треба посматрати у асемблеру

Индекс је у `w4`, а број појављивања у `w3`:

```asm
mov w3, #0
mov w4, #0
```

Сваки елемент читамо истим обрасцем као у основном примеру са сумом:

```asm
ldr w5, [x0, x4, lsl #2]
```

Ако елемент није једнак траженој вредности, само настављамо петљу. Ако јесте, увећавамо бројач:

```asm
cmp w5, w2
b.ne nastavak
add w3, w3, #1
```

## Датотеке

- `main.cpp` чита низ, тражену вредност и позива `prebroj_pojavljivanja`
- `prebroj_pojavljivanja.s` садржи ARM64 имплементацију функције

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp prebroj_pojavljivanja.s -o prebroj_pojavljivanja
```

## Покретање

```sh
qemu-aarch64 ./prebroj_pojavljivanja
```

Пример интеракције:

```text
7
3 1 3 2 3 4 1
3
3
```

## На шта треба обратити пажњу

- петља увек пролази кроз цео низ
- повратна вредност је бројач у `w0`
- ако се вредност не појављује, резултат је `0`
- функција је leaf функција и зато јој не треба стек оквир
