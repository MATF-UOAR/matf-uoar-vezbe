# Индекс максимума

Овај пример враћа индекс највећег елемента у низу. Вредност максимума се прати као у основном примеру, али се као резултат враћа позиција, не сама вредност.

## Шта програм ради

Програм учитава дужину низа и елементе, позива `indeks_maksimuma` и исписује индекс првог највећег елемента.

Референтна C++ функција је:

```cpp
int indeks_maksimuma(int* a, int n) {
    int max = a[0];
    int indeks = 0;
    for (int i = 1; i < n; i++) {
        if (a[i] > max) {
            max = a[i];
            indeks = i;
        }
    }
    return indeks;
}
```

Подразумевамо да је `n > 0`, јер почетну вредност узимамо из `a[0]`.

## Шта треба посматрати у асемблеру

Почетни максимум је `a[0]`, а почетни индекс је `0`:

```asm
ldr w2, [x0]
mov w3, #0
mov w4, #1
```

Када нађемо строго већи елемент, ажурирамо и максимум и индекс:

```asm
cmp w5, w2
b.le nastavak
mov w2, w5
mov w3, w4
```

Пошто ажурирамо само на строго већи елемент, ако се максимум појави више пута, враћа се индекс првог појављивања.

## Датотеке

- `main.cpp` чита низ и позива `indeks_maksimuma`
- `indeks_maksimuma.s` садржи ARM64 имплементацију функције

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp indeks_maksimuma.s -o indeks_maksimuma
```

## Покретање

```sh
qemu-aarch64 ./indeks_maksimuma
```

Пример интеракције:

```text
6
4 9 2 9 5 1
1
```

## На шта треба обратити пажњу

- резултат је индекс, а не вредност максимума
- `w2` чува текући максимум, а `w3` његов индекс
- пример подразумева непразан низ
- функција је leaf функција и зато јој не треба стек оквир
