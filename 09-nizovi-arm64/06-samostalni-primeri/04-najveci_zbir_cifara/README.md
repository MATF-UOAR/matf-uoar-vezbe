# Највећи збир цифара

Овај пример пролази кроз низ `unsigned` бројева и враћа највећи збир цифара неког елемента. То је умерено проширење: спољна петља пролази кроз низ, а унутрашња петља рачуна збир цифара једног броја.

## Шта програм ради

Програм учитава дужину низа и елементе, позива `najveci_zbir_cifara` и исписује највећи збир цифара.

Референтна C++ функција је:

```cpp
unsigned zbir_cifara(unsigned x) {
    unsigned zbir = 0;
    while (x != 0) {
        zbir += x % 10;
        x /= 10;
    }
    return zbir;
}

unsigned najveci_zbir_cifara(unsigned* a, int n) {
    unsigned max_zbir = 0;
    for (int i = 0; i < n; i++) {
        unsigned zbir = zbir_cifara(a[i]);
        if (zbir > max_zbir) {
            max_zbir = zbir;
        }
    }
    return max_zbir;
}
```

## Шта треба посматрати у асемблеру

Спољна петља чита један елемент низа:

```asm
ldr w4, [x0, x3, lsl #2]
mov w5, #0
```

Унутрашња петља издваја последњу цифру помоћу `udiv` и `msub`, као у задацима из претходне недеље:

```asm
udiv w6, w4, w10
msub w7, w6, w10, w4
add w5, w5, w7
mov w4, w6
```

Када се збир цифара једног броја заврши, поредимо га са највећим до сада:

```asm
cmp w5, w2
csel w2, w5, w2, hi
```

Пошто су вредности неозначене, услов `hi` значи да је нови збир строго већи.

## Датотеке

- `main.cpp` чита низ `unsigned` бројева и позива `najveci_zbir_cifara`
- `najveci_zbir_cifara.s` садржи ARM64 имплементацију функције

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp najveci_zbir_cifara.s -o najveci_zbir_cifara
```

## Покретање

```sh
qemu-aarch64 ./najveci_zbir_cifara
```

Пример интеракције:

```text
5
12 409 77 1000 95
14
```

## На шта треба обратити пажњу

- спољна петља пролази кроз низ, а унутрашња кроз цифре једног броја
- број `0` има збир цифара `0`
- `w10` чува константу `10`
- функција је leaf функција и зато јој не треба стек оквир
