# Самостални мини-примери

Ова целина садржи четири мања готова примера за самосталан рад после девете недеље. Намерно су ближи основним примерима из ове недеље него претрагама и сортирањима која траже више алгоритамске организације.

Идеја је да се утврди:

- пролазак кроз низ преко базе и индекса
- услов у телу петље
- бројање елемената који испуњавају услов
- памћење индекса, а не само вредности елемента
- комбиновање проласка кроз низ са већ познатим издвајањем цифара

## Препоручен редослед

1. Почните од [Линеарне претраге](./01-linearna_pretraga/README.md), јер је најкраћи пример са раним изласком из петље.
2. Затим урадите [Број појављивања](./02-prebroj_pojavljivanja/README.md), где се уместо раног изласка пролази кроз цео низ и одржава бројач.
3. После тога пређите на [Индекс максимума](./03-indeks_maksimuma/README.md), јер се поред текуће највеће вредности памти и њена позиција.
4. На крају урадите [Највећи збир цифара](./04-najveci_zbir_cifara/README.md), који додаје унутрашњу петљу за цифре сваког елемента.

## Како да их радите

За сваки пример прво напишите кратку C++ функцију, па онда преведите један по један део у ARM64:

- одредите који аргумент стиже у који регистар
- изаберите регистре за индекс, текући елемент и резултат
- преведите услов петље у `cmp` и `b.<услов>`
- тек на крају додајте ажурирање резултата

Сви примери у овој целини су leaf функције и зато им не треба стек оквир.
