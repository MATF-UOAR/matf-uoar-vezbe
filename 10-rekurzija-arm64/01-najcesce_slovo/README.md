# Најчешће слово

Овај пример повезује рад са нискама из претходне недеље са позивом
помоћне функције. Функција пролази кроз реч, прави локални низ бројача за
слова од `'a'` до `'z'`, а затим позива функцију која налази индекс највећег
бројача.

## Шта програм ради

Програм учитава непразну реч састављену од малих слова енглеске абецеде и
исписује слово које се у њој појављује највише пута. Ако више слова има исти
максималан број појављивања, исписује се слово које је прво у абецеди.

Референтна C++ верзија могла би да изгледа овако:

```cpp
unsigned indeks_maksimuma(unsigned *a, unsigned n) {
    unsigned indeks = 0;
    for (unsigned i = 1; i < n; i++) {
        if (a[i] > a[indeks]) {
            indeks = i;
        }
    }
    return indeks;
}

char najcesce_slovo(const char *s) {
    unsigned brojaci[26] = {};

    while (*s != '\0') {
        brojaci[*s - 'a']++;
        s++;
    }

    return 'a' + indeks_maksimuma(brojaci, 26);
}
```

## Датотеке

- `main.cpp` учитава реч и позива `najcesce_slovo`
- `najcesce_slovo.s` прави и попуњава локални низ бројача
- `indeks_maksimuma.s` налази индекс првог максималног бројача

## Шта треба посматрати у асемблеру

Низ `brojaci` има `26` елемената типа `unsigned`, односно заузима `104`
бајта. Функција чува `fp` и `lr`, а затим користи оквир од укупно `128`
бајтова, тако да `sp` остаје поравнат на `16` бајтова пре позива:

```asm
stp fp, lr, [sp, #-128]!
mov fp, sp
add x4, sp, #16
```

Регистар `x4` показује на почетак локалног низа бројача. Сваки бројач се
прво нулира инструкцијом:

```asm
str wzr, [x4, w5, uxtw #2]
```

Карактер се чита као један бајт. Пошто претпостављамо мала слова, разлика
`s[i] - 'a'` је индекс од `0` до `25`:

```asm
ldrb w5, [x0], #1
sub w5, w5, #97
ldr w6, [x4, w5, uxtw #2]
add w6, w6, #1
str w6, [x4, w5, uxtw #2]
```

После проласка кроз ниску, адреса локалног низа и његова дужина постају
аргументи помоћне функције:

```asm
mov x0, x4
mov w1, #26
bl indeks_maksimuma
```

`indeks_maksimuma` мења резултат само када пронађе строго већи бројач.
Зато при изједначењу остаје мањи индекс, односно абецедно раније слово.

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp najcesce_slovo.s indeks_maksimuma.s -o najcesce_slovo
```

## Покретање

```sh
qemu-aarch64 ./najcesce_slovo
```

Пример интеракције:

```text
programiranje
r
```

## На шта треба обратити пажњу

- овај пример претпоставља непразну ниску састављену од слова `'a'` до `'z'`
- карактер се чита инструкцијом `ldrb`, док су бројачи четворобајтни и читају
  се и уписују инструкцијама `ldr` и `str`
- локални низ се налази у стек оквиру, али се његова адреса прослеђује
  помоћној функцији као и адреса било ког другог низа
- `najcesce_slovo` није leaf функција, па мора да сачува `lr` пре `bl`
