# Најчешће слово

Овај пример повезује рад са нискама из претходне недеље са позивом
помоћне функције. Функција пролази кроз реч, прави локални низ бројача за
слова од `'a'` до `'z'` независно од величине слова, а затим позива функцију
која налази индекс највећег бројача.

## Шта програм ради

Програм учитава ниску која садржи бар једно слово енглеске абецеде и исписује
слово које се у њој појављује највише пута, не разликујући мала и велика
слова. Остале карактере игнорише, а резултат увек исписује као мало слово.
Ако више слова има исти максималан број појављивања, исписује се слово које
је прво у абецеди.

Референтна C++ верзија могла би да изгледа овако:

```cpp
unsigned indeks_maksimuma(unsigned *a, unsigned n) {
    unsigned indeks = 0;
    for (unsigned i = 1; i < n; i++) {
        if (a[i] > a[indeks]) {
            indeks = i;
        }
    }
    return indeks;
}

char najcesce_slovo(const char *s) {
    unsigned brojaci[26] = {};

    while (*s != '\0') {
        char c = *s;
        if ('A' <= c && c <= 'Z') {
            c += 'a' - 'A';
        }
        if ('a' <= c && c <= 'z') {
            brojaci[c - 'a']++;
        }
        s++;
    }

    return 'a' + indeks_maksimuma(brojaci, 26);
}
```

## Датотеке

- `main.cpp` учитава реч и позива `najcesce_slovo`
- `najcesce_slovo.s` прави и попуњава локални низ бројача
- `indeks_maksimuma.s` налази индекс првог максималног бројача

## Шта треба посматрати у асемблеру

Низ `brojaci` има `26` елемената типа `unsigned`, односно заузима `104`
бајта. Функција прво чува `fp` и `lr`, а затим одваја `112` бајтова за
локалне податке. Тако оквир има укупно `128` бајтова, а `sp` остаје поравнат
на `16` бајтова пре позива:

```asm
stp fp, lr, [sp, #-16]!
mov fp, sp
sub sp, sp, #112
mov x4, sp
```

Регистар `x4` показује на почетак локалног низа бројача. Сваки бројач се
прво нулира инструкцијом:

```asm
str wzr, [x4, x5, lsl #2]
```

Карактер се чита као један бајт. Ако је велико слово, претварамо га у мало
додавањем разлике `'a' - 'A'`. Ако карактер није слово, прелазимо на следећи.
За мало слово разлика `s[i] - 'a'` је индекс од `0` до `25`:

```asm
ldrb w5, [x0], #1
cmp w5, #'a'
b.lo proveri_veliko_slovo
cmp w5, #'z'
b.ls uvecaj_brojac

proveri_veliko_slovo:
cmp w5, #'A'
b.lo brojaci_spremni
cmp w5, #'Z'
b.hi brojaci_spremni
add w5, w5, #('a' - 'A')

uvecaj_brojac:
sub w5, w5, #'a'
ldr w6, [x4, x5, lsl #2]
add w6, w6, #1
str w6, [x4, x5, lsl #2]
```

У адресном изразу `lsl #2` помера индекс улево за `2` бита, односно множи га
са `4`, јер сваки бројач заузима `4` бајта. Користимо `x5`, 64-битни облик
регистра, а горња `32` бита су нуле јер сваки упис у `w5` брише горњу
половину одговарајућег регистра `x5`.

После проласка кроз ниску, адреса локалног низа и његова дужина постају
аргументи помоћне функције:

```asm
mov x0, x4
mov w1, #26
bl indeks_maksimuma
```

`indeks_maksimuma` мења резултат само када пронађе строго већи бројач.
Зато при изједначењу остаје мањи индекс, односно абецедно раније слово.

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp najcesce_slovo.s indeks_maksimuma.s -o najcesce_slovo
```

## Покретање

```sh
qemu-aarch64 ./najcesce_slovo
```

Пример интеракције:

```text
ProgRAMIRANJE
r
```

## На шта треба обратити пажњу

- велика и мала слова се броје заједно, а резултат је увек мало слово
- карактери који нису слова енглеске абецеде се игноришу
- ниска треба да садржи бар једно слово енглеске абецеде
- карактер се чита инструкцијом `ldrb`, док су бројачи четворобајтни и читају
  се и уписују инструкцијама `ldr` и `str`
- локални низ се налази у стек оквиру, али се његова адреса прослеђује
  помоћној функцији као и адреса било ког другог низа
- `najcesce_slovo` није leaf функција, па мора да сачува `lr` пре `bl`
