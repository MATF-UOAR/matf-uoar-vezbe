# Рекурзивна дужина ниске

Ово је кратак пример рекурзије над показивачем на карактере.

## Шта програм ради

Функција `duzina_niske_rekurzivno` враћа број карактера у ниски пре
завршног бајта `'\0'`.

Референтна C++ верзија је:

```cpp
int duzina_niske_rekurzivno(const char *s) {
    if (*s == '\0') {
        return 0;
    }

    return 1 + duzina_niske_rekurzivno(s + 1);
}
```

## Датотеке

- `main.cpp` чита ниску и позива `duzina_niske_rekurzivno`
- `duzina_niske_rekurzivno.s` садржи ARM64 имплементацију функције

## Шта треба посматрати у асемблеру

Карактер је један бајт, па се чита инструкцијом `ldrb`:

```asm
ldrb w1, [x0]
cmp w1, #0
```

Ако је стигао завршни бајт, резултат је `0`. У супротном се показивач
помера за један бајт, рекурзивно се добија дужина остатка ниске и на њу се
додаје `1`:

```asm
add x0, x0, #1
bl duzina_niske_rekurzivno
add w0, w0, #1
```

За разлику од рекурзивне суме низа, овде не чувамо елемент пре позива:
увек додајемо исту константу `1`.

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp duzina_niske_rekurzivno.s -o duzina_niske_rekurzivno
```

## Покретање

```sh
qemu-aarch64 ./duzina_niske_rekurzivno
```

Пример интеракције:

```text
rekurzija
9
```

## На шта треба обратити пажњу

- базни случај је `*s == '\0'`
- `s + 1` значи померање адресе за један бајт
- после повратка из рекурзије додаје се само `1`, па нема локалне вредности за чување
- функција чува `lr`, јер сама ради `bl`
