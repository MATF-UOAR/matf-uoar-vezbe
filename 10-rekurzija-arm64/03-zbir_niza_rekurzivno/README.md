# Рекурзивна сума низа

Овај пример примењује рекурзију над низом: сваки позив обрађује први
елемент преосталог дела низа и прослеђује следећу адресу дубљем позиву.

## Шта програм ради

Функција `zbir_niza_rekurzivno` враћа збир првих `n` елемената низа.

Референтна C++ верзија је:

```cpp
int zbir_niza_rekurzivno(int *a, int n) {
    if (n == 0) {
        return 0;
    }

    return a[0] + zbir_niza_rekurzivno(a + 1, n - 1);
}
```

## Датотеке

- `main.cpp` чита низ и позива `zbir_niza_rekurzivno`
- `zbir_niza_rekurzivno.s` садржи ARM64 имплементацију функције

## Шта треба посматрати у асемблеру

Базни случај је празан остатак низа, чији је збир `0`. У рекурзивном
случају тренутни елемент мора да се сачува пре позива, јер резултат дубљег
позива долази у `w0`:

```asm
ldr w2, [x0]
str w2, [sp]
```

Пошто је елемент типа `int`, показивач на следећи елемент добија се
померањем за `4` бајта:

```asm
add x0, x0, #4
sub w1, w1, #1
bl zbir_niza_rekurzivno
```

Тек при одмотавању позива сачувани елемент се додаје суми остатка низа:

```asm
ldr w1, [sp]
add w0, w0, w1
```

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp zbir_niza_rekurzivno.s -o zbir_niza_rekurzivno
```

## Покретање

```sh
qemu-aarch64 ./zbir_niza_rekurzivno
```

Пример интеракције:

```text
3
2 -5 7
4
```

## На шта треба обратити пажњу

- за `n == 0` резултат је `0`
- `a + 1` код низа `int` значи адресу померену за `4` бајта
- вредност `a[0]` мора да преживи рекурзивни позив
- функција чува `lr`, јер сама ради `bl`
