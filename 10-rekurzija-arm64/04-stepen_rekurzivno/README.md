# Брзи рекурзивни степен

Овај пример уводи рекурзију преко алгоритма брзог степеновања. Уместо да
за `a^n` правимо `n` множења, експонент у сваком рекурзивном кораку
преполовимо.

## Шта програм ради

Функција `stepen_rekurzivno` рачуна `a^n` за `unsigned` вредности.

Референтна C++ верзија је:

```cpp
unsigned stepen_rekurzivno(unsigned a, unsigned n) {
    if (n == 0) {
        return 1;
    }

    unsigned p = stepen_rekurzivno(a, n / 2);
    if (n % 2 == 0) {
        return p * p;
    }
    return a * p * p;
}
```

За паран експонент важи `a^n = (a^(n/2))^2`. За непаран експонент остаје
још један множилац `a`. Тако дубина рекурзије и број множења постају
`O(log n)`, уместо `O(n)`.

## Датотеке

- `main.cpp` чита базу и експонент и исписује резултат
- `stepen_rekurzivno.s` садржи ARM64 имплементацију брзог степеновања

## Шта треба посматрати у асемблеру

Аргументи `a` и `n` стижу у `w0` и `w1`. Пошто после рекурзивног позива
`w0` садржи резултат `p`, а `w1` више није старо `n`, обе почетне вредности
које нам могу затребати чувамо у стек оквиру:

```asm
str w0, [sp, #16]
str w1, [sp, #20]
```

Базни случај `n == 0` враћа `1`. У рекурзивном случају дељење експонента
са `2` радимо логичким померањем удесно:

```asm
lsr w1, w1, #1
bl stepen_rekurzivno
```

После повратка `w0` садржи `p = a^(n / 2)`, па резултат прво квадрирамо:

```asm
mul w0, w0, w0
```

Затим проверимо најнижи бит сачуваног експонента. Ако је `n` непаран,
производ множимо још једном базом:

```asm
ldr w1, [sp, #20]
tst w1, #1
b.eq kraj
ldr w1, [sp, #16]
mul w0, w0, w1
```

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp stepen_rekurzivno.s -o stepen_rekurzivno
```

## Покретање

```sh
qemu-aarch64 ./stepen_rekurzivno
```

Пример интеракције:

```text
3 5
3^5 = 243
```

## На шта треба обратити пажњу

- базни случај је `a^0 = 1`
- рекурзивни позив добија `n / 2`, не `n - 1`
- `tst w1, #1` проверава да ли је сачувани експонент непаран
- функција чува `lr`, јер сама ради `bl`
