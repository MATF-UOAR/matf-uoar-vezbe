# Нађи први преко predicate функције

Овај пример уводи индиректан позив функције у ARM64. Функција не зна
унапред који услов проверава над елементима низа; добија адресу predicate
функције као аргумент и позива је за сваки елемент док не нађе први погодак.

## Шта програм ради

Функција `nadji_prvi` пролази кроз низ `unsigned` вредности и враћа индекс
првог елемента за који прослеђена predicate функција врати ненула вредност.
Ако такав елемент не постоји, враћа `-1`.

Референтна C++ верзија могла би да изгледа овако:

```cpp
int nadji_prvi(unsigned *a, int n, int (*pred)(unsigned)) {
    for (int i = 0; i < n; i++) {
        if (pred(a[i])) {
            return i;
        }
    }
    return -1;
}
```

Програм позива исту асемблерску функцију са два различита услова: први
позив тражи паран елемент, а други први елемент већи од `99`.

## Датотеке

- `main.cpp` чита низ, дефинише две predicate функције и позива `nadji_prvi`
- `nadji_prvi.s` садржи ARM64 имплементацију претраге и индиректног позива

## Шта треба посматрати у асемблеру

Потпис функције је:

```cpp
int nadji_prvi(unsigned *a, int n, int (*pred)(unsigned));
```

Аргументи у ARM64 стижу овако:

- `x0` је адреса првог елемента низа
- `w1` је број елемената
- `x2` је адреса predicate функције

Позвана predicate функција сме да препише caller-saved регистре. Зато
`nadji_prvi` у свом стек оквиру чува низ, адресу функције, дужину и индекс
петље:

```asm
str x0, [sp, #16]
str x2, [sp, #24]
str w1, [sp, #32]
str wzr, [sp, #36]
```

У свакој итерацији текући елемент постаје први аргумент predicate функције.
Адреса функције се учитава у регистар, а затим се ради индиректан позив:

```asm
ldr w0, [x4, w3, sxtw #2]
ldr x8, [sp, #24]
blr x8
```

Инструкција `blr` одговара позиву преко показивача на функцију: као и `bl`,
она уписује повратну адресу у `lr`, али циљ позива долази из регистра уместо
из именоване лабеле.

Ако predicate врати ненулу, враћа се сачувани индекс и претрага се одмах
завршава. У супротном се индекс повећава и обрада наставља:

```asm
cmp w0, #0
b.ne nadjen
```

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp nadji_prvi.s -o nadji_prvi
```

## Покретање

```sh
qemu-aarch64 ./nadji_prvi
```

Пример интеракције:

```text
6
11 15 18 21 130 7
prvi paran: indeks 2
prvi > 99: indeks 4
```

## На шта треба обратити пажњу

- `blr` је ARM64 облик индиректног позива преко адресе у регистру
- стање петље мора да преживи сваки позив predicate функције
- predicate добија један `unsigned` аргумент у `w0` и враћа резултат у `w0`
- резултат је индекс првог поготка, па се петља завршава чим услов успе
- `-1` означава да ниједан елемент не задовољава услов
