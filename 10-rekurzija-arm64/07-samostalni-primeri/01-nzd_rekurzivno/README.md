# Рекурзивни НЗД

Овај пример преводи познати Еуклидов алгоритам у рекурзивни ARM64 облик.

## Шта програм ради

Функција `nzd_rekurzivno` враћа највећи заједнички делилац два неозначена
броја.

Референтна C++ верзија је:

```cpp
unsigned nzd_rekurzivno(unsigned a, unsigned b) {
    if (b == 0) {
        return a;
    }

    return nzd_rekurzivno(b, a % b);
}
```

## Датотеке

- `main.cpp` чита два броја и исписује њихов НЗД
- `nzd_rekurzivno.s` садржи ARM64 имплементацију функције

## Шта треба посматрати у асемблеру

Базни случај је `b == 0`; у том тренутку је `a` већ у регистру повратне
вредности `w0`.

За рекурзивни позив потребан је остатак `a % b`. Као у недељи 8, ARM64
израчунава количник инструкцијом `udiv`, а остатак инструкцијом `msub`:

```asm
udiv w2, w0, w1
msub w2, w2, w1, w0
mov w0, w1
mov w1, w2
bl nzd_rekurzivno
```

Овде нема додатног рада после повратка из рекурзије: резултат дубљег позива
је одмах и резултат тренутног позива.

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp nzd_rekurzivno.s -o nzd_rekurzivno
```

## Покретање

```sh
qemu-aarch64 ./nzd_rekurzivno
```

Пример интеракције:

```text
48 18
NZD(48, 18) = 6
```

## На шта треба обратити пажњу

- `udiv` и `msub` раде са `unsigned` аргументима
- аргументи следећег позива су `b` и `a % b`
- функција ипак чува `lr`, јер рекурзивно ради `bl`
