# Рекурзивна бинарна претрага

Овај пример користи рекурзију над сортираним низом. Уместо проласка кроз
све елементе, сваки позив одбацује половину преосталог опсега.

## Шта програм ради

Функција `binarna_pretraga_rekurzivno` прима растуће сортиран низ, границе
опсега и тражену вредност. Враћа индекс пронађене вредности или `-1` ако
вредност није у низу.

Референтна C++ верзија је:

```cpp
int binarna_pretraga_rekurzivno(int *a, int levo, int desno, int x) {
    if (levo > desno) {
        return -1;
    }

    int sredina = levo + (desno - levo) / 2;
    if (a[sredina] == x) {
        return sredina;
    }
    if (a[sredina] < x) {
        return binarna_pretraga_rekurzivno(a, sredina + 1, desno, x);
    }
    return binarna_pretraga_rekurzivno(a, levo, sredina - 1, x);
}
```

## Датотеке

- `main.cpp` чита сортиран низ и тражену вредност
- `binarna_pretraga_rekurzivno.s` садржи ARM64 имплементацију функције

## Шта треба посматрати у асемблеру

Четири аргумента стижу у `x0`, `w1`, `w2` и `w3`: база низа, лева
граница, десна граница и тражена вредност. Средњи индекс се рачуна без
сабирања две границе пре дељења:

```asm
sub w4, w2, w1
asr w4, w4, #1
add w4, w1, w4
```

Елемент се дохвата преко средњег индекса, а поређење одређује који нови
опсег стиже у рекурзивни позив:

```asm
ldr w5, [x0, w4, sxtw #2]
cmp w5, w3
```

Функција не ради ништа са добијеним резултатом после рекурзивног позива, па
довољно је да га остави у `w0` и врати се.

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp binarna_pretraga_rekurzivno.s -o binarna_pretraga_rekurzivno
```

## Покретање

```sh
qemu-aarch64 ./binarna_pretraga_rekurzivno
```

Пример интеракције:

```text
6
-5 1 4 8 12 20
12
4
```

## На шта треба обратити пажњу

- претпостављамо да је улазни низ сортиран растуће
- базни случај `levo > desno` враћа `-1`
- поређења елемената и индекса су означена, јер су аргументи типа `int`
- рекурзивни позив добија само леву или само десну половину опсега
