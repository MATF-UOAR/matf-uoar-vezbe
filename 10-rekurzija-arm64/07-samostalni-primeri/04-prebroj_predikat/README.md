# Преброј преко predicate функције

Овај пример је наставак функције `nadji_prvi`: адреса услова се и даље
прослеђује као аргумент и позива инструкцијом `blr`, али сада обилазимо цео
низ и бројимо све поготке.

## Шта програм ради

Функција `prebroj_predikat` враћа број елемената низа за које predicate
функција врати ненула вредност.

Референтна C++ верзија је:

```cpp
int prebroj_predikat(unsigned *a, int n, int (*pred)(unsigned)) {
    int broj = 0;
    for (int i = 0; i < n; i++) {
        if (pred(a[i])) {
            broj++;
        }
    }
    return broj;
}
```

## Датотеке

- `main.cpp` чита низ и позива функцију са условима `paran` и `veci_od_99`
- `prebroj_predikat.s` садржи ARM64 имплементацију функције

## Шта треба посматрати у асемблеру

Као у главном примеру `nadji_prvi`, низ, дужина, индекс и адреса predicate
функције морају да преживе сваки индиректан позив. Ново је да и бројач
погодака мора да остане у стек оквиру:

```asm
str x0, [sp]
str x2, [sp, #8]
str w1, [sp, #16]
str wzr, [sp, #20]
str wzr, [sp, #24]
```

За сваки елемент ради се исти индиректан позив:

```asm
ldr w0, [x4, w3, sxtw #2]
ldr x8, [sp, #8]
blr x8
```

Ако је добијена вредност ненула, бројач се увећава, али петља не престаје
као у `nadji_prvi`.

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp prebroj_predikat.s -o prebroj_predikat
```

## Покретање

```sh
qemu-aarch64 ./prebroj_predikat
```

Пример интеракције:

```text
6
11 15 18 21 130 7
parnih: 2
> 99: 1
```

## На шта треба обратити пажњу

- `blr` позива predicate функцију чија је адреса стигла као аргумент
- бројач резултата мора да преживи сваки позив
- за разлику од `nadji_prvi`, функција наставља до краја низа и после поготка
