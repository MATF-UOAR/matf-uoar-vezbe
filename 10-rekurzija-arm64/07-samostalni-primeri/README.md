# Самостални мини-примери

Ови задаци су допуна главним примерима из недеље 10. Сваки користи већ
виђене ARM64 обрасце, али их примењује у новом алгоритму или са другачијим
стањем које мора да преживи позив.

## Садржај

- [Рекурзивни НЗД](./01-nzd_rekurzivno/README.md)
- [Рекурзивно обртање ниске](./02-obrni_nisku_rekurzivno/README.md)
- [Рекурзивна бинарна претрага](./03-binarna_pretraga_rekurzivno/README.md)
- [Преброј преко predicate функције](./04-prebroj_predikat/README.md)

## Препоручени редослед

1. Почните од [Рекурзивног НЗД-а](./01-nzd_rekurzivno/README.md), јер је то кратка рекурзивна варијанта већ познатог Еуклидовог алгоритма.
2. Наставите са [Рекурзивним обртањем ниске](./02-obrni_nisku_rekurzivno/README.md), које се надовезује на палиндром, али уписује нове бајтове у меморију.
3. Потом урадите [Рекурзивну бинарну претрагу](./03-binarna_pretraga_rekurzivno/README.md), где рекурзивни позив добија само једну половину сортираног низа.
4. На крају погледајте [Преброј преко predicate функције](./04-prebroj_predikat/README.md), који надограђује `nadji_prvi` тако што наставља петљу после сваког поготка.

## Шта се увежбава

| пример | главна идеја |
| --- | --- |
| `nzd_rekurzivno` | рекурзивни позив са промењеним аргументима и без рада после повратка |
| `obrni_nisku_rekurzivno` | рекурзија над два показивача и измена ниске инструкцијом `strb` |
| `binarna_pretraga_rekurzivno` | избор једне половине опсега и више аргумената функције |
| `prebroj_predikat` | поновљени `blr` позиви и чување бројача погодака |
