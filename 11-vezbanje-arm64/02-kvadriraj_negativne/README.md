# Квадрирај негативне елементе

У асемблеру имплементирати функцију која квадрира све негативне елементе
низа целих бројева. Низ се мења у месту.

Референтна C++ верзија:

```cpp
void kvadriraj_negativne(int *a, int n) {
    for (int i = 0; i < n; i++) {
        if (a[i] < 0) {
            a[i] *= a[i];
        }
    }
}
```

## Датотеке

- `main.cpp` чита низ, позива функцију и исписује измењен низ
- `kvadriraj_negativne.s` садржи ARM64 имплементацију функције

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp kvadriraj_negativne.s -o kvadriraj_negativne
```

## Покретање

```sh
qemu-aarch64 ./kvadriraj_negativne
```

Пример:

```text
6
3 4 -1 2 -5 3
3 4 1 2 25 3
```

## На шта треба обратити пажњу

- елемент низа се чита преко базе и индекса: `a + i * 4`
- поређење са нулом је означено, јер су елементи типа `int`
- функција нема повратну вредност, већ уписује нове вредности у меморију
