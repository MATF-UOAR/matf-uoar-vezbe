# Скаларни производ

У асемблеру имплементирати функцију која рачуна скаларни производ два низа
исте дужине.

Референтна C++ верзија:

```cpp
int skalarni_proizvod(int *a, int *b, int n) {
    int suma = 0;
    for (int i = 0; i < n; i++) {
        suma += a[i] * b[i];
    }
    return suma;
}
```

## Датотеке

- `main.cpp` чита два низа и исписује њихов скаларни производ
- `skalarni_proizvod.s` садржи ARM64 имплементацију функције

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp skalarni_proizvod.s -o skalarni_proizvod
```

## Покретање

```sh
qemu-aarch64 ./skalarni_proizvod
```

Пример:

```text
3
1 2 3
4 5 6
32
```

## На шта треба обратити пажњу

- у истој петљи користе се две базне адресе, `x0` и `x1`
- исти индекс чита `a[i]` и `b[i]`
- производ се рачуна инструкцијом `mul`, а затим додаје у акумулатор
