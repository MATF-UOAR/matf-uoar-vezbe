# Замени минимум и максимум

У асемблеру имплементирати функцију која проналази позиције најмањег и
највећег елемента низа, а затим та два елемента мења местима.

Референтна C++ верзија:

```cpp
void zameni_min_i_max(int *a, int n) {
    if (n <= 1) {
        return;
    }

    int i_min = 0;
    int i_max = 0;
    for (int i = 1; i < n; i++) {
        if (a[i] < a[i_min]) {
            i_min = i;
        }
        if (a[i] > a[i_max]) {
            i_max = i;
        }
    }

    int pom = a[i_min];
    a[i_min] = a[i_max];
    a[i_max] = pom;
}
```

## Датотеке

- `main.cpp` чита низ, позива функцију и исписује измењен низ
- `zameni_min_i_max.s` садржи ARM64 имплементацију функције

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp zameni_min_i_max.s -o zameni_min_i_max
```

## Покретање

```sh
qemu-aarch64 ./zameni_min_i_max
```

Пример:

```text
5
4 -2 7 0 3
4 7 -2 0 3
```

## На шта треба обратити пажњу

- петља памти и вредности и индексе минимума и максимума
- користе се означена поређења `lt` и `gt`
- измена меморије се ради тек после проласка кроз цео низ
