# Број речи

У асемблеру имплементирати функцију која броји речи у ниски. Речи су
непразни делови ниске раздвојени размаком. Више узастопних размака броји се
као један раздвајач.

Референтна C++ верзија:

```cpp
unsigned broj_reci(const char *s) {
    unsigned broj = 0;
    bool u_reci = false;

    while (*s != '\0') {
        if (*s == ' ') {
            u_reci = false;
        } else if (!u_reci) {
            broj++;
            u_reci = true;
        }
        s++;
    }

    return broj;
}
```

## Датотеке

- `main.cpp` чита целу линију текста и исписује број речи
- `broj_reci.s` садржи ARM64 имплементацију функције

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp broj_reci.s -o broj_reci
```

## Покретање

```sh
qemu-aarch64 ./broj_reci
```

Пример:

```text
  arm64  vezbanje lepo radi
4
```

## На шта треба обратити пажњу

- ниска се чита бајт по бајт инструкцијом `ldrb`
- посебан регистар памти да ли смо тренутно унутар речи
- завршни бајт `'\0'` означава крај петље
