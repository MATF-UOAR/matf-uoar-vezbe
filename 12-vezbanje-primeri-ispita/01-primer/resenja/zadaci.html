Технички детаљи

  • Све задатке сачувати у фолдеру који је направљен на Desktop-у са вашим подацима.
  • У архиви се налазе датотеке 1.cpp, 2.cpp, 3.cpp и 4.cpp.
  • Није дозвољено мењати .cpp датотеке.
  • Потребно је направити и имплементирати тражене функције у одговарајућим .s датотекама.
  • У задацима је дозвољено користити претходно имплементиране функције.
  • Унутар .s датотека је дозвољено имплементирати и помоћне функције уколико сматрате да је то потребно.

Задатак 1 — x86-64

У датотеци 1.s имплементирати функцију:

extern "C" int vise_parnih_cifara(long* a, int n);

Функција прима низ ненегативних целих бројева a дужине n. Потребно је вратити број елемената низа који у свом децималном запису имају строго више парних цифара него непарних цифара.

Цифра 0 се сматра парном. Број 0 има једну цифру, и то цифру 0.

Ако је n <= 0, функција враћа 0.

Датотека 1.cpp учитава n, затим n бројева у реду, позива функцију и исписује повратну вредност.

Задатак 2 — x86-64

Дата је помоћна функција (имплементирана у 2.cpp):

extern "C" void minmax(long* a, int n, long* pmin, long* pmax);

Функција minmax за низ a дужине n > 0 уписује најмањи елемент на адресу pmin, а највећи на адресу pmax.

У датотеци 2.s имплементирати функцију:

extern "C" int broj_unutrasnjih(long* a, int n);

Функција враћа број елемената низа који су строго већи од минимума и строго мањи од максимума низа. Променљиве за минимум и максимум морају бити локалне променљиве на стеку. Није дозвољено користити глобалне променљиве.

Ако је n <= 0, функција враћа 0.

Датотека 2.cpp учитава n, затим n бројева у реду, позива функцију и исписује повратну вредност.

Задатак 3 — ARM64

У датотеци 3.s имплементирати функцију:

extern "C" int ocisti(char* s);

Функција мења ниску s на месту и враћа број измењених карактера.

Правила izmene:

  • ако је карактер цифра од '0' до '9', замењује се карактером '#';
  • ако је карактер велико слово од 'A' до 'Z', претвара се у одговарајуће мало слово;
  • сви остали карактери остају непромењени.

Ниска је завршена нул-карактером '\0'.

Датотека 3.cpp учитава један ред текста, позива функцију и исписује измењену ниску, а затим број измењених карактера.

Izlaz:

a# bz!

Задатак 4 — ARM64

Дата је помоћна функција (имплементирана у 4.cpp):

extern "C" int saren(long x);

Број је шарен ако се у његовом децималном запису суседне цифре увек разликују по парности. Једноцифрен број је увек шарен.

У датотеци 4.s имплементирати функцију:

extern "C" long saberi_sarene(long* a, int n);

Функција пролази кроз све елементе низа и за сваки a[i] позива saren(a[i]) помоћу инструкције bl. Ако saren врати вредност различиту од нуле, a[i] се додаје у збир. Функција враћа добијени збир.

Ако је n <= 0, функција враћа 0. Може се претпоставити да су сви елементи ненегативни.

Датотека 4.cpp учитава n, затим n бројева у реду, позива функцију и исписује повратну вредност.
