Технички детаљи

  • Све задатке сачувати у фолдеру који је направљен на Desktop-у са вашим подацима.
  • У архиви се налазе датотеке 1.cpp, 2.cpp, 3.cpp и 4.cpp.
  • Није дозвољено мењати .cpp датотеке.
  • Потребно је направити и имплементирати тражене функције у одговарајућим .s датотекама.
  • У задацима је дозвољено користити претходно имплементиране функције.
  • Унутар .s датотека је дозвољено имплементирати и помоћне функције уколико сматрате да је то потребно.

Задатак 1 - x86-64

У датотеци 1.s имплементирати функцију:

extern "C" unsigned long tezina(unsigned long x);

Тежина ненегативног броја је збир квадрата његових децималних цифара. Тежина броја 0 је 0.

Датотека 1.cpp учитава број x, позива функцију и исписује повратну вредност.

Задатак 2 — x86-64

Користити функцију tezina из претходног задатка. У датотеци 2.s имплементирати функцију:

extern "C" unsigned long najtezi(unsigned long* a, int n);

Функција прима низ a дужине n. Потребно је проначи и вратити елемент који има највећу тежину. Функцију tezina је потребно позвати помоћу инструкције bl.

Ако више елемената има исту највећу тежину, враћа се први такв елемент у низу.

Ако је n <= 0, функција враћа 0.

Датотека 2.cpp учитава n, затим n бројева у реду, позива функцију и исписује повратну вредност. При превођењу повезати и датотеку 1.s.

Задатак 3 — ARM64

У датотеци 3.s имплементирати функцију:

extern "C" int broj_u_opsegu(unsigned long* a, int n,
                             unsigned long l, unsigned long d);

Функција прима низ a дужине n и две границе l и d. Потребно је вратити број елемената који припадаю затвореном интервалу [l, d].

Може се претпоставити да је l <= d.

Ако је n <= 0, функција враћа 0.

Датотека 3.cpp учитава n, затим n бројева у реду, затим l и d у истом реду, позива функцију и исписује повратну вредност.

Задатак 4 — ARM64

Дате су помоћне функције (имплементиране у 4.cpp):

extern "C" void statistika(unsigned long* a, int n,
                           unsigned long* pmean,
                           unsigned long* pmedian);

extern "C" int broj_u_opsegu(unsigned long* a, int n,
                             unsigned long l, unsigned long d);

Функција statistika за низ a дужине n > 0 уписује целобројну аритметичку средину на адресу pmean и медијану на адреси pmedian.

У датотеци 4.s имплементирати функцију:

extern "C" int broj_tipicnih(unsigned long* a, int n);

Функција преброји колико елемената низа се налази измеѓу аритметичке средине и медијане (уключујући границе). За бројање користити функцију broj_u_opsegu. Променљиве за средину и медијану морају бити локалне променљиве на стеку. Није дозвољено користити глобалне променљиве.

Ако је n <= 0, функција враћа 0.

Датотека 4.cpp учитава n, затим n бројева у реду, позива функцију и исписује повратну вредност. При превођењу повезати и датотеку 3.s.
