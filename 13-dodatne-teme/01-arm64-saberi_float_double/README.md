# ARM64: сабирање `float` и `double` бројева

Код ARM64 архитектуре аргументи типа `float` и `double` не стижу у `x0`, `x1`,
већ у регистре за реалне бројеве.

Референтне C++ функције:

```cpp
float saberi_float(float a, float b) {
    return a + b;
}

double saberi_double(double a, double b) {
    return a + b;
}
```

## Датотеке

- `main.cpp` чита два `float` и два `double` броја и исписује обе суме
- `saberi_float_double.s` садржи ARM64 имплементације функција

## Шта треба посматрати у асемблеру

Код ARM64 архитектуре регистри `v0`, `v1`, ... могу да се посматрају на више
начина. Када радимо са једним `float` бројем користимо 32-битни поглед `s0`,
а када радимо са једним `double` бројем користимо 64-битни поглед `d0`.

```text
float:   s0 + s1 -> s0     fadd s0, s0, s1
double:  d0 + d1 -> d0     fadd d0, d0, d1
```

Иста инструкција `fadd` ради сабирање реалних бројева, а ширина регистра говори
да ли се сабирају `float` или `double` вредности.

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp saberi_float_double.s -o saberi_float_double
```

## Покретање

```sh
qemu-aarch64 ./saberi_float_double
```

Пример:

```text
1.5 2.25
1.5 2.25
3.750000
3.750000
```

## На шта треба обратити пажњу

- `float` аргументи стижу у `s0` и `s1`, а резултат се враћа у `s0`
- `double` аргументи стижу у `d0` и `d1`, а резултат се враћа у `d0`
- ове функције су leaf функције и не треба им стек оквир
