# ARM64: аритметичка средина `int` низа

У овом примеру петља је и даље обична петља кроз `int` низ. Нова идеја је да
целобројну суму на крају претворимо у реалан број и поделимо је реалном
инструкцијом.

Референтна C++ функција:

```cpp
float aritmeticka_sredina(int *a, int n) {
    int suma = 0;
    for (int i = 0; i < n; i++) {
        suma += a[i];
    }
    return (float)suma / n;
}
```

## Датотеке

- `main.cpp` чита низ и исписује аритметичку средину
- `aritmeticka_sredina.s` садржи ARM64 имплементацију функције

## Шта треба посматрати у асемблеру

Први део функције је познат: читамо `int` елементе и сабирамо их у целобројни
регистар. Тек на крају прелазимо у регистре за реалне бројеве:

```asm
scvtf s0, w2
scvtf s1, w1
fdiv s0, s0, s1
```

Инструкција `scvtf` значи signed convert to floating-point: означени цео број
се претвара у реалан број. После тога `fdiv` ради реално дељење.

Честе конверзије изгледају овако:

| Извор | У `float` | У `double` |
| --- | --- | --- |
| `int` | `scvtf s0, w2` | `scvtf d0, w2` |
| `unsigned int` | `ucvtf s0, w2` | `ucvtf d0, w2` |

За `long` и `unsigned long` користи се 64-битни изворни регистар:
`scvtf s0, x2`, `scvtf d0, x2`, `ucvtf s0, x2` или `ucvtf d0, x2`.
За `short` и `char` вредности прво проширимо вредност у `w` регистар, па онда
користимо исти облик као за `int`. При читању из меморије то обично значи
`ldrsh` или `ldrsb` за означене типове, а `ldrh` или `ldrb` за неозначене.

Визуелно:

```text
w2 = 10      scvtf      s0 = 10.0
w1 = 4       scvtf      s1 = 4.0
                         fdiv s0, s0, s1  ->  2.5
```

Подразумевамо да је `n > 0`.

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp aritmeticka_sredina.s -o aritmeticka_sredina
```

## Покретање

```sh
qemu-aarch64 ./aritmeticka_sredina
```

Пример:

```text
4
1 2 3 4
2.500000
```

## На шта треба обратити пажњу

- `w2` је целобројни акумулатор за суму
- `scvtf` није обично премештање битова, већ прави реалну вредност
- за дељење реалних бројева користимо `fdiv`, не `udiv` или `sdiv`
