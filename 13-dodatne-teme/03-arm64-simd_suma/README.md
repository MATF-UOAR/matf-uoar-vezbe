# ARM64: SIMD сума низа

Функција рачуна суму `int` низа помоћу SIMD инструкција. У свакој итерацији
чита четири елемента.

Референтна C++ функција је иста као код обичне суме:

```cpp
int suma_simd(int *a, int n) {
    int suma = 0;
    for (int i = 0; i < n; i++) {
        suma += a[i];
    }
    return suma;
}
```

У овом примеру подразумевамо да је `n` дељиво са `4`.

## Датотеке

- `main.cpp` чита низ и исписује суму
- `suma_simd.s` садржи ARM64 SIMD имплементацију

## Шта треба посматрати у асемблеру

Регистар `v0.4s` значи: посматрај `v0` као четири 32-битне траке. Свака трака
чува један `int`.

```text
низ:        [1] [2] [3] [4]   [5] [6] [7] [8]

после 1. читања:
v1.4s =     [1] [2] [3] [4]
v0.4s =     [1] [2] [3] [4]

после 2. читања:
v1.4s =     [5] [6] [7] [8]
v0.4s =     [6] [8] [10] [12]

addv:       6 + 8 + 10 + 12 = 36
```

Кључне инструкције су:

```asm
ldr  q1, [x0], #16
add  v0.4s, v0.4s, v1.4s
addv s0, v0.4s
```

`ldr q1, [x0], #16` учитава 16 бајтова, односно четири `int` вредности.
Инструкција `add` сабира по тракама, а `addv` на крају сабира све траке једног
вектора у један резултат.

## Превођење

```sh
aarch64-linux-gnu-g++ main.cpp suma_simd.s -o suma_simd
```

## Покретање

```sh
qemu-aarch64 ./suma_simd
```

Пример:

```text
8
1 2 3 4 5 6 7 8
36
```

## На шта треба обратити пажњу

- `movi v0.4s, #0` поставља све четири траке акумулатора на нулу
- индекс није потребан, јер се показивач `x0` помера за `16` бајтова после сваког читања
- `add` у овом облику није скаларно сабирање, већ четири сабирања одједном
- `addv` је хоризонтално сабирање: од четири траке прави један број
