# x86-64: аритметичка средина `int` низа

Ово је x86-64 пример у ком задржавамо познату целобројну петљу кроз низ, а
тек на крају резултат претварамо у `float`.

Референтна C++ функција:

```cpp
float aritmeticka_sredina(int *a, int n) {
    int suma = 0;
    for (int i = 0; i < n; i++) {
        suma += a[i];
    }
    return (float)suma / n;
}
```

## Датотеке

- `main.cpp` чита низ и исписује аритметичку средину
- `aritmeticka_sredina.s` садржи x86-64 имплементацију функције

## Шта треба посматрати у асемблеру

Сума се рачуна у `eax`, као и у ранијим x86-64 примерима са низовима. На крају
се и сума и `n` претварају у `float`:

```asm
cvtsi2ss xmm0, eax
cvtsi2ss xmm1, esi
divss xmm0, xmm1
```

Инструкција `cvtsi2ss` претвара означени цео број у scalar single-precision
вредност. Инструкција `divss` дели две `float` вредности.

Честе конверзије изгледају овако:

| Извор | У `float` | У `double` |
| --- | --- | --- |
| `int` | `cvtsi2ss xmm0, eax` | `cvtsi2sd xmm0, eax` |
| `unsigned int` | `mov eax, edi`<br>`cvtsi2ss xmm0, rax` | `mov eax, edi`<br>`cvtsi2sd xmm0, rax` |

Инструкције `cvtsi2ss` и `cvtsi2sd` раде означену конверзију. Зато код
`unsigned int` вредности прво нулама проширимо број у 64-битни регистар, па га
онда конвертујемо као позитиван 64-битни број.

За `long` се користи 64-битни регистар или меморијски операнд:
`cvtsi2ss xmm0, rax` или `cvtsi2sd xmm0, rax`. За `unsigned long` нема једне
једноставне SSE инструкције која покрива све 64-битне вредности; ако је вредност
у опсегу означеног `long`, може да се користи исти облик као за `long`, а за
пун опсег је потребна дужа секвенца. За `short` и `char` вредности прво урадимо
`movsx` за означене типове или `movzx` за неозначене, па онда користимо исти
облик као за `int`.

Визуелно:

```text
eax = 10     cvtsi2ss     xmm0 = 10.0
esi = 4      cvtsi2ss     xmm1 = 4.0
                           divss xmm0, xmm1  ->  2.5
```

Подразумевамо да је `n > 0`. За примере на часу можемо задржати да је `n`
дељиво са `4`, иако сама скаларна петља не зависи од те претпоставке.

## Превођење

```sh
g++ main.cpp aritmeticka_sredina.s -o aritmeticka_sredina
```

## Покретање

```sh
./aritmeticka_sredina
```

Пример:

```text
4
1 2 3 4
2.500000
```

## На шта треба обратити пажњу

- `eax` чува целобројну суму до самог краја петље
- `cvtsi2ss` прави реалан број, не копира само битове у `xmm` регистар
- за `float` дељење користимо `divss`, не `idiv` или `div`
