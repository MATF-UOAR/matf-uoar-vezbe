# x86-64: SIMD сума низа

Функција рачуна суму `int` низа помоћу SIMD инструкција на x86-64. У свакој
итерацији читамо четири `int` елемента.

Референтна C++ функција:

```cpp
int suma_simd(int *a, int n) {
    int suma = 0;
    for (int i = 0; i < n; i++) {
        suma += a[i];
    }
    return suma;
}
```

У овом примеру подразумевамо да је `n` дељиво са `4`.

## Датотеке

- `main.cpp` чита низ и исписује суму
- `suma_simd.s` садржи x86-64 SIMD имплементацију

## Шта треба посматрати у асемблеру

Регистар `xmm0` посматрамо као четири 32-битна цела броја. Инструкција `paddd`
сабира packed doubleword вредности, односно четири пара `int` вредности у једној
инструкцији.

```text
низ:        [1] [2] [3] [4]   [5] [6] [7] [8]

после 1. читања:
xmm1 =      [1] [2] [3] [4]
xmm0 =      [1] [2] [3] [4]

после 2. читања:
xmm1 =      [5] [6] [7] [8]
xmm0 =      [6] [8] [10] [12]
```

После петље резултат није још један број, него четири делимичне суме. Зато на
крају радимо хоризонталну редукцију: копирамо регистар, померимо копију за 8
бајтова, саберемо, па исто поновимо са померањем за 4 бајта.

У том последњем кораку користимо инструкцију `psrldq`. Она помера бајтове у
целом `xmm` регистру ка нижим позицијама: најнижи бајтови се одбацују, а највиши
се попуњавају нулама. Пошто један `int` заузима 4 бајта, `psrldq xmm1, 8`
помера садржај за две `int` траке, а `psrldq xmm1, 4` за једну `int` траку.

У дијаграмима најнижу `int` траку пишемо лево. Зато се ефекат `psrldq` види као
прелазак вредности са десне стране улево. На пример, ако после петље имамо:

```text
xmm0 = [6] [8] [10] [12]
```

прво сабирамо доњу и горњу половину регистра:

```text
movdqa xmm1, xmm0
psrldq xmm1, 8

xmm0 = [6]  [8]  [10] [12]
xmm1 = [10] [12] [0]  [0]

paddd xmm0, xmm1
xmm0 = [16] [20] [10] [12]
```

После тога су прве две траке `16` и `20`, па их треба сабрати међусобно. Зато
поново копирамо регистар, померамо копију за једну `int` траку и сабирамо:

```text
movdqa xmm1, xmm0
psrldq xmm1, 4

xmm0 = [16] [20] [10] [12]
xmm1 = [20] [10] [12] [0]

paddd xmm0, xmm1
xmm0 = [36] [30] [22] [12]
```

Сада је у првој траци цела сума: `6 + 8 + 10 + 12 = 36`. Остале траке више нису
важне. Инструкција `movd eax, xmm0` пребацује само ту прву траку у `eax`, што је
повратна вредност функције.

## Превођење

```sh
g++ main.cpp suma_simd.s -o suma_simd
```

## Покретање

```sh
./suma_simd
```

Пример:

```text
8
1 2 3 4 5 6 7 8
36
```

## На шта треба обратити пажњу

- `pxor xmm0, xmm0` поставља SIMD акумулатор на нулу
- `movdqu` учитава 16 бајтова, односно четири `int` вредности
- `paddd` сабира четири 32-битне траке одједном
- `psrldq` помера цео `xmm` регистар за задати број бајтова и убацује нуле
- после SIMD петље потребан је још један корак да се четири делимичне суме сведу на један резултат
