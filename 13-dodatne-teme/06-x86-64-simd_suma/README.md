# x86-64: SIMD сума низа

Функција рачуна суму `int` низа помоћу SIMD инструкција на x86-64. У свакој
итерацији читамо четири `int` елемента.

Референтна C++ функција:

```cpp
int suma_simd(int *a, int n) {
    int suma = 0;
    for (int i = 0; i < n; i++) {
        suma += a[i];
    }
    return suma;
}
```

У овом примеру подразумевамо да је `n` дељиво са `4`.

## Датотеке

- `main.cpp` чита низ и исписује суму
- `suma_simd.s` садржи x86-64 SIMD имплементацију

## Шта треба посматрати у асемблеру

Регистар `xmm0` посматрамо као четири 32-битна цела броја. Инструкција `paddd`
сабира packed doubleword вредности, односно четири пара `int` вредности у једној
инструкцији.

```text
низ:        [1] [2] [3] [4]   [5] [6] [7] [8]

после 1. читања:
xmm1 =      [1] [2] [3] [4]
xmm0 =      [1] [2] [3] [4]

после 2. читања:
xmm1 =      [5] [6] [7] [8]
xmm0 =      [6] [8] [10] [12]
```

После петље резултат није још један број, него четири делимичне суме. Зато на
крају радимо хоризонталну редукцију: копирамо регистар, померимо копију за 8
бајтова, саберемо, па исто поновимо са померањем за 4 бајта.

## Превођење

```sh
g++ main.cpp suma_simd.s -o suma_simd
```

## Покретање

```sh
./suma_simd
```

Пример:

```text
8
1 2 3 4 5 6 7 8
36
```

## На шта треба обратити пажњу

- `pxor xmm0, xmm0` поставља SIMD акумулатор на нулу
- `movdqu` учитава 16 бајтова, односно четири `int` вредности
- `paddd` сабира четири 32-битне траке одједном
- после SIMD петље потребан је још један корак да се четири делимичне суме сведу на један резултат
