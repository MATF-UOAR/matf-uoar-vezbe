## Основна идеја

До сада су скоро сви резултати били целобројни и чували су се у регистрима као
што су `eax`, `x0`, `w0`. Реални бројеви користе други део процесора: регистре
за рад са реалним бројевима и SIMD вредностима. Због тога се мењају и регистри
за аргументе и инструкције које користимо.

Кратка слика:

```text
скаларно:
    s0 = [3.5]          fadd/addss     s0 = [5.0]
    s1 = [1.5]

векторски:
    v0.4s = [1] [2] [3] [4]
    v1.4s = [5] [6] [7] [8]
    add   = [6] [8] [10] [12]
    addv  = 6 + 8 + 10 + 12
```

У скаларном примеру инструкција ради над једним бројем. У SIMD примеру исти
регистар посматрамо као неколико мањих поља, која зовемо траке или lane-ови.
Инструкција `add v0.4s, v0.4s, v1.4s`, на пример, сабира четири пара
32-битних вредности одједном.

У задацима са SIMD сумом користимо низове чија је дужина дељива са `4`.

## Конвенција позива

У овим материјалима ARM64 примери прате AAPCS64 конвенцију, а x86-64 примери
прате Linux System V ABI.

### ARM64

Целобројни и показивачки аргументи и даље стижу у `x0`-`x7`, односно `w0`-`w7`
за 32-битне вредности. Реални и SIMD аргументи користе регистре `v0`-`v7`.
Ове две групе регистара броје се одвојено.

| Група | Регистри | Практично правило |
| --- | --- | --- |
| `float` аргументи и резултат | `s0`-`s7`, резултат у `s0` | `s0` је доњих 32 бита регистра `v0`. |
| `double` аргументи и резултат | `d0`-`d7`, резултат у `d0` | `d0` је доњих 64 бита регистра `v0`. |
| SIMD аргументи и резултат | `v0`-`v7`, резултат у `v0` | Исти регистар можемо гледати као `v0.4s`, `v0.2d`, итд. |
| `caller-saved` | `v0`-`v7`, `v16`-`v31` | Ако су нам потребни после `bl`, морамо да их сачувамо пре позива. |
| `callee-saved` | `v8`-`v15`, само доњих 64 бита | Ако их позвана функција користи, мора да врати доњих 64 бита. |

Због последњег реда се у овим примерима не ослањамо на то да ће цео `q8`-`q15`
регистар преживети позив функције. Ако нам је потребна цела 128-битна SIMD
вредност после позива, чувамо је сами.

Примери:

```cpp
float saberi_float(float a, float b);
// a -> s0, b -> s1, rezultat -> s0

float aritmeticka_sredina(int *a, int n);
// a -> x0, n -> w1, rezultat -> s0
```

### x86-64

За x86-64 користимо Linux конвенцију позива. Целобројни и показивачки аргументи
и даље стижу у `rdi`, `rsi`, `rdx`, `rcx`, `r8`, `r9`. Реални и SIMD аргументи
користе `xmm` регистре. Ове две групе регистара броје се одвојено.

| Група | Регистри | Практично правило |
| --- | --- | --- |
| `float` аргументи и резултат | `xmm0`-`xmm7`, резултат у `xmm0` | Инструкције као `addss`, `divss` раде над `float` вредностима. |
| `double` аргументи и резултат | `xmm0`-`xmm7`, резултат у `xmm0` | Инструкције као `addsd`, `divsd` раде над `double` вредностима. |
| SIMD аргументи и резултат | `xmm0`-`xmm7`, резултат у `xmm0` | Исти регистар можемо гледати као више 32-битних или 64-битних поља. |
| `caller-saved` | `xmm0`-`xmm15` | Позвана функција сме да их препише. |
| `callee-saved` | нема `xmm` регистара | Ако нам `xmm` вредност треба после `call`, чувамо је пре позива. |

Општенаменски callee-saved регистри остају исти као раније: `rbx`, `rbp`,
`r12`, `r13`, `r14`, `r15`.

Примери:

```cpp
double saberi_double(double a, double b);
// a -> xmm0, b -> xmm1, rezultat -> xmm0

float aritmeticka_sredina(int *a, int n);
// a -> rdi, n -> esi, rezultat -> xmm0
```
